Find PS5 IP

Find the console LAN address in Settings → Network → View Connection Status. When using a PC or phone, enter the PS5 address here. Browser detection does not discover another device on your network.

Downloader setup & connection help

For console downloads, install the matching receiver helper and keep ezRemote Server running. Opening its page does not save a file. Choose and verify storage in the native downloader.

Use the paired sender when the browser cannot contact your PS5 loader. Open its local host page and enter the token printed on your computer. Nothing loads until you choose a payload.

Download desktop sender · Sender instructions

Download uses the configured console downloader, which checks its queue and destination before saving. Without a console address, it downloads to this device. A transfer acknowledgement does not confirm execution; check the console for the result.

Afterglow setup

PS4 13.52 / 14.00 only. Use the console’s browser and a reachable HTTP host. Choose the bundled ps4-hen or GoldHEN on the isolated landing page, then Start. Autostart is off initially; opting in remembers the choice and gives a five-second countdown. Cancel also clears a pending start while files cache. Returning from a restored/reloaded run page requires a fresh entry.

Choose HEN Download runtimeDownload source

For local hosting, extract the runtime ZIP, enter its web/ folder and use serve.sh with Python3 and a POSIX shell, or the included Windows-compatible Python server (python serve.py --port 8000). Open the server’s LAN address on PS4. A computer-only localhost URL is not reachable from the console.

Serve JavaScript as text/javascript, appcache as text/cache-manifest, and revalidate runtime files with Cache-Control: no-cache, must-revalidate. Offline installation and hardware execution have not been tested.

Payload and failure requirements

The bundled ps4-hen is patched pre-release-main-182. An unpatched upstream 14.00 build can freeze app launches. The bundled GoldHEN has no independently established numeric version. It uses this runtime’s exact per-firmware patchsets; it is separate from the GoldHEN downloads page. Selecting firmware never makes other payloads compatible.

If the page says the handles are NOT defused, do not close the browser; cold start the console. For an ordinary WebKit failure, follow the reopen-browser message. A kernel crash may produce no message. Save your work before a run.

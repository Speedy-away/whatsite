PS4 · native workspace

Payload files & autoload

Browse console files, upload ready payloads and edit the existing autoload file through ezRemote Client. The installed helper verifies backups and re-reads saved files.

Install the console workspace
  1. Download PS4 workspace helper
  2. Use ezRemote Client or FTP to copy this HTML file to /data/whatsite-workspace-ps4.html.
  3. Keep ezRemote Client running, then open the workspace above. Its filesystem controls work only through the matching console origin.

The public page cannot directly access console storage. Opening the native workspace does not upload, overwrite or run a payload.

Autoload edits preserve a verified backup and refuse a stale original. Editing a queue does not start it; review its native settings before the next launch.

PS4 · native GoldHEN controls

Payload LaunchPad & AutoRun

Use a compatible GoldHEN release that includes PayLoader LaunchPad. Its native list manages payload launches and AutoRun on the PS4.

  1. Save compatible payloads in the location required by your GoldHEN release, using the PS4 file manager.
  2. On the PS4, open GoldHEN → Utilities → PayLoader LaunchPad.
  3. Highlight the payload and use Square to add it to AutoRun. Review the list before restarting GoldHEN.

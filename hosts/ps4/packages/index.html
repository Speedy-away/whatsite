Package installation

Download a console-compatible PKG through your native receiver first. Keep ezRemote Client running, then open the native package helper to verify the saved path and send it to the console’s installer.

Download PS4 package installer helper

Install it through ezRemote at /data/whatsite-package-installer-ps4.html, then open http://CONSOLE-IP:8080/data/whatsite-package-installer-ps4.html.

Nothing installs when this page opens. The helper checks the saved filename, size and partial-download marker before enabling an explicit installation request. It does not treat an accepted request as a completed installation.

The reviewed PS4 installer may replace or uninstall an existing title while retrying a native registration conflict. Review its confirmation before requesting installation.

The background receiver displays its native completion notification with the destination path. Receiver-reported completion does not verify the final saved file’s checksum.

PS5 · UMTX ELF loader

Run the locally hosted PSFree / UMTX chain, then wait for the native ELF listener on port 9021. This pinned loader excludes 5.xx because upstream documents that ELF loading is broken there.

Wait for the loader's own readiness message before sending a matching .elf to TCP 9021. Use only files built for this console, firmware and loader ABI.

Prepared from a pinned upstream build. Hardware execution has not been tested.

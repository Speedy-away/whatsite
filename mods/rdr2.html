Before You Install

Back Up First

Copy your game folder and save files before installing anything. It is far quicker than a reinstall.

Single Player Only

Use mods offline. Loading them into online modes can get your account banned.

Official Sources

Every link here points at the mod author or the main community site. Avoid re-uploads.

Game Updates

A game patch usually breaks script hooks. Wait for the mod to update rather than forcing it.

Get online with Pretendo

Pretendo Network provides replacement online services for supported 3DS games and features. Begin with its official 3DS guide and the complete Nimbus package below. Support varies by game, feature and public or test channel.

Open Pretendo Network Official 3DS installation guide Set up Nimbus

Keep your existing NNID. Pretendo’s guide says removing it is unnecessary and can lose associated data. A PNID is a separate Pretendo account. Do not perform a system transfer as part of this setup; Pretendo’s documentation lists transfers as unsupported.

Install the complete Nimbus package

  1. Prepare the console and connectionUse an already homebrewed 3DS/2DS with current Luma3DS; Pretendo’s guide requires Luma 13+. Check your SD backup and confirm the console’s Internet connection test succeeds.
  2. Copy the complete releasePower off before removing the SD card. Extract combined.2.2.0.zip at the SD root, preserving its folders. Back up existing files before applying the package. Keep the IPS patches, certificate and Nimbus plugin under /3ds/nimbus/update/ with the CIA or 3DSX.
  3. Enable the documented Luma optionsHold Select while powering on. Enable loading external FIRMs/modules and game patching, then press Start to save. These are the options in Pretendo’s 3DS guide.
  4. Launch NimbusFor HOME Menu use, install /cias/nimbus.cia with FBI. Alternatively open /3ds/nimbus.3dsx with Homebrew Launcher. Select Pretendo in Nimbus and follow its prompts. The selected network persists across restarts.
  5. Use a PNID when neededMany game services do not require a PNID, while some features do. Use the official guide to create one on the console or link an existing Pretendo account. Choose a PNID username different from the NNID already linked to this console.
  6. Check a supported titleConfirm the exact game, region, update, feature and service availability before testing. Keep the packaged Nimbus plugin available where the guide requires it. A working Nimbus installation does not establish support for every 3DS game.

StreetPass over the internet with NetPass

NetPass is a separate service. Its installation guide requires system software 11.15 or later, recommends 11.17, and calls for current Luma3DS. Install the CIA or use the 3DSX, open the app and choose a virtual location. Encounters are exchanged with other visitors; this does not turn a game into real-time online multiplayer.

Connection and account checks

  1. Start with the connection testUse System Settings → Internet Settings → Connection Settings and run the connection test. If it fails before reaching the internet, check the router details, security key and wireless settings using Nintendo’s instructions before changing service files.
  2. Update the complete Nimbus installationThe 2.2.0 release says existing users must update to continue using the service and adds account-repair support. Check the release notes and official forum for your exact error code. Keep your original SD backup.
  3. Check the selected networkReopen Nimbus and confirm Pretendo is selected when testing a Pretendo-supported game. Select Nintendo to return to the original account environment; that choice does not restore discontinued Nintendo game servers.
  4. Protect existing account dataKeep the NNID linked. Use a different username for the PNID. Badge Arcade data can disappear when switching between networks because the saved data and service account differ; read Pretendo’s badge guidance before changing it.
  5. Separate support from connectivityA successful Wi-Fi test or PNID login does not mean every game, feature or test service is supported. Check the exact title, version and current service notices. Keep the error code, Nimbus version and Luma version when seeking help.

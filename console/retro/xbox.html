Use your original Xbox

These downloads target the original Xbox and its .xbe executable format. Start with an existing, working softmod or compatible modchip/TSOP setup. Xbox 360 XEX and Xbox One/Series APPX packages require different consoles.

  1. Keep the working boot setupIdentify your Xbox hardware revision and use your chosen setup project’s requirements. Preserve the existing boot dashboard, EEPROM backup and recovery files. The apps below do not install a softmod or replace your boot dashboard.
  2. Copy a complete release folderDownload on your PC or phone, extract the ZIP and transfer the full application folder using your existing dashboard’s file manager or FTP. Example E:/Apps paths assume that partition exists; verify your own storage layout.
  3. Launch from the current dashboardOpen the extracted default.xbe from your established dashboard. Retain its companion assets and original archive. No model, RAM upgrade or BIOS compatibility beyond the publisher’s documentation is asserted.

LithiumX · v0.9.7

A native nxdk dashboard with title browsing, artwork support and an FTP server.

Download LithiumX.zipPublisher release
Setup & checksum

Extract the complete folder to an applications directory on your existing homebrew-enabled Xbox, such as E:/Apps/LithiumX/. Launch default.xbe from your current dashboard. The first launch creates E:/UDATA/LithiumX/lithiumx.toml for search paths.

This original repository is archived. Its v0.9.7 notes fix cache clearing affecting E:/CACHE. Keep your existing dashboard and configuration; no boot-dashboard replacement is required.

NevolutionX · v0.2.1

An original Xbox dashboard and application launcher built with nxdk. The release ZIP contains a native Xbox ISO.

Download NevolutionX.zipPublisher release
Setup & checksum

Extract NevolutionX.iso from the ZIP, then use an Xbox XISO-aware tool on your PC to extract its complete application folder. Transfer default.xbe and all companion assets together to a separate directory, for example E:/Apps/NevolutionX/, and launch from your current dashboard. The project documents DHCP networking and an automatically started FTP server with xbox/xbox credentials.

The nevox_hdd.zip emulator HDD image is deliberately excluded. This is the native application ISO in its original ZIP, not an emulator HDD image or a directly installable folder ZIP.

SDLPoPX · v1.22

The original Xbox port of the SDLPoP Prince of Persia engine.

Download SDLPoP_Xbox.zipPublisher release
Setup & checksum

Extract the complete Xbox release into a separate game folder, for example E:/Games/SDLPoPX/. Keep the supplied data and configuration beside default.xbe, then launch it from your existing dashboard.

Use the Xbox ZIP linked here. The similarly named Xbox-Homebrew/SDLPoP release is an APPX/UWP build, which is not an original Xbox XBE.

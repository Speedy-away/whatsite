Theme, BGM or splash?

ItemWhat changesFiles and location
HOME Menu themeMenu backgrounds, colours, folders and optional sounds.body_LZ.bin inside the theme ZIP. Keep the ZIP in /Themes/ for Anemone.
Background musicThe HOME Menu music; it can be installed separately from the visual theme.Optional bgm.bcstm in the bundle. A preview audio file is not automatically installable BGM.
Luma boot splashThe image shown during startup, before HOME Menu.splash.bin / splashbottom.bin. Keep the source ZIP in /Splashes/; Anemone installs the active files to /luma/.

Theme and splash files are separate formats. Use the corresponding 3DS section and Anemone mode. Switch NXTheme files do not install as 3DS HOME Menu themes.

Install a theme with Anemone3DS

  1. Prepare HOME Menu theme dataOn the console, open HOME Menu Settings → Change Theme and select a basic colour once, then return to HOME Menu. If Change Theme is absent, stop and check the console’s HOME Menu region and the guide’s theme support notes. Do not region-change just to apply a theme.
  2. Install the official managerUse Anemone3DS CIA on CFW, or its 3DSX through Luma’s Rosalina Homebrew Launcher. Open it once so its theme and splash folders are created.
  3. Copy the original ZIPsPower off before removing the SD. Put each downloaded theme ZIP directly in /Themes/. Keep its body_LZ.bin and any bgm.bcstm together inside the ZIP; do not rename them to Switch formats. Put only actual 3DS splash ZIPs in /Splashes/.
  4. Preview and applyIn Anemone’s theme mode, choose a theme and press Y to preview. Hold A, hold Up, then release A to install the full theme and its included music. Follow Anemone’s displayed exit instructions after installation.
  5. Choose visuals or music separatelyHold A + Right, then release A to install the visuals while preserving existing BGM. Hold A + Left, then release A to install only the chosen theme’s BGM. This does not mute music; use a music-free theme or HOME Menu’s basic theme for that.
  6. Optional: shuffle themesPress B to queue between 2 and 10 themes. Hold A + Down and release A to install a shuffle set. The theme changes when HOME Menu closes and reopens.

Use a Luma boot splash

  1. Choose a 3DS splashOpen Themezer’s 3DS splash section and check the item’s preview, author and actual 3DS splash download. The bundled downloads above are HOME Menu themes.
  2. Install in splash modeIn Anemone, press L or the touchscreen S to switch to splashes, select a splash and press A. The installed splash lives in /luma/ on the SD card.
  3. Enable the Luma splash settingPower off, hold Select at startup and set the documented Luma Splash option to Before or After rather than Off. Save configuration. Keep the SD inserted for an SD-based splash.

Change, remove or troubleshoot

  1. Return to a basic themeOpen HOME Menu Settings → Change Theme and select a basic theme. Keep your downloaded ZIPs if you want to reinstall later; removing a file from the library does not restore the menu by itself.
  2. Turn off a boot splashSet Luma’s Splash option to Off to stop displaying it while retaining the files. Anemone’s B action in splash mode deletes active splash files, so keep a source ZIP before using it.
  3. Check storage and region firstUse FAT32 storage and initialise the HOME Menu’s theme data. Match the currently installed HOME Menu region after any prior region change; CHN / KOR / TWN HOME Menus have theme-support limits. Use Anemone’s troubleshooting notes before changing extdata.
  4. Keep an original backupBack up the SD card, themes and saves before repairing extdata. Check the exact failure message and current Anemone release. The bundled files were inspected; physical-console installation remains untested.

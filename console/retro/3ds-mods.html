Install a Luma game patch

  1. Identify the exact titleCheck the game’s region and update with your installed title manager. Use the title ID documented by the mod; do not copy a code patch into a folder based only on a similar game name.
  2. Keep a recovery copyBack up the game save and the existing /luma/titles// folder. Keep each mod’s original release archive so you can restore the matching files later.
  3. Follow the supplied folder layoutA LayeredFS mod normally places replacements under /luma/titles//romfs/. Code patches use the specific code.ips or code.bps and exheader.bin supplied for that revision. Preserve directory names and use the project’s instructions.
  4. Enable game patchingPower on while holding Select, enable Luma’s game-patching option and save. Launch the game normally, then check the mod’s documented success sign.
  5. Use one coherent setupA manager can keep separate slots. Do not combine two code patches or merge incompatible romfs files unless their authors document that combination. To return to stock behaviour, restore the backed-up title folder or move the mod folder out of the active title path.

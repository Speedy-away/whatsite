Wiimmfi · DNS disc method

A no-homebrew route for a limited set of retail-disc games, including Mario Kart Wii and Super Smash Bros. Brawl. It is not a universal patch for every Wii game.

Primary DNS95.217.77.181
Secondary DNS1.1.1.1
  1. Choose the active connectionOpen Wii Settings → Internet → Connection Settings → Change Settings.
  2. Set DNS manuallySet Auto-Obtain DNS to No, open Advanced Settings and enter the two values above.
  3. Test and launch the retail discComplete the connection test without accepting a System Update, then start the supported game from the Disc Channel.

These values were corroborated in the maintained guide on 2 November 2026. Error 20100 or 20110 can indicate that this route does not support your game.

Wiimmfi · Homebrew Channel disc method

For supported retail discs, use the archived Auto Wiimmfi Patcher below: copy its apps folder to SD/USB root, launch it in Homebrew Channel and let it patch the inserted disc before booting. This is a launch-time disc patch, separate from DNS configuration.

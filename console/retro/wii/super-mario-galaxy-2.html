Choose your Galaxy mod

These are mod/patch packages and homebrew tools. Supply the original game disc each mod requires. Match the game, region and revision; keep full packages separate and back up existing saves/settings before updating. No downloaded file was executed or physically tested on a console.

Neo Mario Galaxy supplies a new adventure. The New Green Stars changes star locations and deliberately starts from modified progress. Daredevil Mode adds a separate difficulty challenge.

Offline adventures: these mods do not add network multiplayer.

Riivolution · step by step

  1. Match the original gameGalaxy uses RMG; Galaxy 2 uses SB4. Use the region supported by the selected patch. A Galaxy 2 mod does not patch the first game.
  2. Prepare Homebrew Channel and RiivolutionUse your model’s maintained homebrew guide. Extract the Riivolution ZIP so /apps/riivolution/boot.elf is on FAT32 SD. These patches use an original disc.
  3. Extract the complete modUse a PC/phone archive tool for ZIP or 7z. Copy the mod’s data folder and its riivolution folder to SD root, preserving names. Keep an independent backup before copying files.
  4. Choose saves before launchBack up the game save first. For Daredevil, choose With SD save to keep the mod’s redirected save separate; With Wii save uses the console save. New Green Stars deliberately replaces progress with a 120-star start.
  5. Launch one overhaulInsert the matching game disc, launch Riivolution from Homebrew Channel, enable the selected mod and disable other overhauls. Select the mod’s supported language and save options, then Launch.

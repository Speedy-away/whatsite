Choose your Galaxy mod

These are mod/patch packages and homebrew tools. Supply the original game disc each mod requires. Match the game, region and revision; keep full packages separate and back up existing saves/settings before updating. No downloaded file was executed or physically tested on a console.

Daredevil Mode changes the original Galaxy challenge rules. Super Lillie Galaxy replaces characters and adds visual, dialogue and music changes; its creator recommends Dolphin because Toy Time Galaxy can lag substantially on Wii.

Offline adventures: these mods do not add network multiplayer.

Riivolution · step by step

  1. Match the original gameGalaxy uses RMG; Galaxy 2 uses SB4. Use the region supported by the selected patch. A Galaxy 2 mod does not patch the first game.
  2. Prepare Homebrew Channel and RiivolutionUse your model’s maintained homebrew guide. Extract the Riivolution ZIP so /apps/riivolution/boot.elf is on FAT32 SD. These patches use an original disc.
  3. Extract the complete modUse a PC/phone archive tool for ZIP or 7z. Copy the mod’s data folder and its riivolution folder to SD root, preserving names. Keep an independent backup before copying files.
  4. Choose saves before launchBack up the game save first. For Daredevil, choose With SD save to keep the mod’s redirected save separate; With Wii save uses the console save. New Green Stars deliberately replaces progress with a 120-star start.
  5. Launch one overhaulInsert the matching game disc, launch Riivolution from Homebrew Channel, enable the selected mod and disable other overhauls. Select the mod’s supported language and save options, then Launch.

Super Lillie Galaxy

4.4.0Super Mario Galaxy7z · Riivolution mod data

A character and presentation overhaul starring Lillie, with other Pokémon characters, dialogue, audio and texture changes. Optional cutscene files are separate and are not required or linked here.

Offline mod · creator recommends Dolphin for performance

Requires: Original Super Mario Galaxy; Riivolution on a homebrew Wii for disc setup, SD and a 7z extraction tool on PC/phone.

Download 7z · 40.50 MiB Official project
Setup, compatibility & file details

Compatibility. Creator builds for USA with Japanese/Korean compatibility; PAL support is incomplete, with missing text and a possible Toy Time Galaxy crash despite P appearing in the XML. USA was console-tested by the creator; other regions were Dolphin-tested. Significant Toy Time lag is reported on Wii.

Storage and launch. Extract the 7z. Copy /Lillie1 to SD root and Super Lillie Galaxy.xml into /riivolution, then enable it in Riivolution with the matching disc. Keep the supplied XML and current 4.4.0 data together; optional cutscenes are a separate archive. Keep an original save backup; this patch has no save-redirection option.

Keep these top-level paths: Lillie1, README.txt, riivolution

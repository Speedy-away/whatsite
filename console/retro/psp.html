Start with your PSP

12 native PSP apps, games, ports and emulators, plus ARK-4, CXMB and four theme files. These packages run on the handheld after compatible homebrew access. Each download shows its exact pinned file, size and checksum.

ARK-4 is archived. Its final v4.20.69 r206 release links to ARK-5. Keep the ARK-4 instructions below for that version; use the official FasterARK instructions for the current upstream route.

Current ARK-5 setup ARK-4 setup reference
  1. Check model and firmwareRead Settings → System Settings → System Information. ARK-4’s live install route uses official 6.60 or 6.61 on retail 1000, 2000, 3000, Go and E1000/Street. Follow the project’s separate migration instructions if PRO, ME or another CFW is already installed.
  2. Prepare the correct storageBack up the existing card and saves. Connect by USB or use a reader. Keep the Memory Stick/Go storage’s existing layout. The table below distinguishes the drive’s root from folders inside PSP.
  3. Install ARK-4 live accessIn the final ARK4.zip, copy ARK_01234 into PSP/SAVEDATA/ and ARK_Loader into PSP/GAME/. On Go, put both on the same storage. Eject safely and launch ARK Loader from Game. It must be relaunched after a full reboot unless you separately install cIPL.
  4. Add a native appExtract the selected binary archive. Put its complete app folder, including EBOOT.PBP and bundled resources, under PSP/GAME/. Launch it from Game → Memory Stick or System Storage. Do not copy the unextracted ZIP there.

On a computer, X:/ means the USB drive letter: X:/PSP/GAME/ maps to that device’s ms0:/PSP/GAME/ or ef0:/PSP/GAME/. An app may still use a hard-coded ms0 path; check its requirements. Street has no WLAN, so network features need another model. PC assistants and Vita VPKs are separate from these native PSP files.

PTF and CTF setup

  1. PTF: use the PSP theme menuCopy a .ptf to PSP/THEME/ on the selected device and apply it in Settings → Theme Settings → Theme. The distributor lists the included PTF files for 6.60/6.61 on official or custom firmware.
  2. CTF: match firmware and install CXMBThe included originals are 6.60-labelled CTF files. Use compatible 6.60 CFW with CXMB; a theme’s file extension alone does not prove support for another firmware. Copy the CTF to PSP/THEME/.
  3. Enable CXMB in ARK-4Copy cxmb.prx into seplugins/cxmb/. In ARK Custom Launcher’s file browser, select the PRX, install it for VSH (XMB), and enable it. Restart VSH, then open Theme Settings. Do not register this XMB plugin as always or Game.
  4. Classic PRO/ME configurationFor those CFWs, the CXMB readme specifies ms0:/seplugins/cxmb/cxmb.prx 1 (or ef0:/seplugins/cxmb/cxmb.prx 1) as the first line of seplugins/VSH.txt. Restart VSH after changing it. ARK-4 has its own plugin manager and configuration format.

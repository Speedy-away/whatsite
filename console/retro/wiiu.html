Start with your Wii U environment

Aroma is the current setup path in the maintained Wii U guide. It launches supported WUHB and RPX applications from the Wii U Menu and loads plugins from its environment folder. Older ELF apps and some legacy RPX apps require a separate Tiramisu/Homebrew Launcher route.

Wii U mode and vWii mode have different software and setup. A Wii DOL or Wii Homebrew Channel app is not a Wii U WUHB. Use the maintained guide’s vWii instructions before adding vWii software.

  1. Follow the maintained setup guideUse the Wii U Hacks Guide for initial access, NAND backups, EnvironmentLoader and Aroma. It covers all Wii U models/regions through 5.5.6 in North America and 5.5.5 in other regions. Follow its migration steps for an existing legacy CFW setup. These firmware bounds describe setup, not a promise that every app supports every version.
  2. Prepare SD storageBack up the card before formatting it. The guide specifies FAT32 with 32 KiB allocation units; do not name its volume wiiu. A 32 GB card is enough for most initial setups. Preserve existing environments and saves; merge complete SD-layout packages at the SD root rather than copying the ZIP onto the card.
  3. Install an app or pluginUse a WUHB at the path shown below for Aroma, or preserve the supplied app folder. WPS plugins belong in the Aroma plugins directory. Bundles containing WMS modules must retain those modules as well.
  4. Launch in the correct environmentOpen WUHB apps from the Wii U Menu with Aroma’s homebrew integration. Restart the environment after adding plugins. Use a documented legacy environment for cards labelled legacy RPX; an extension alone does not guarantee Aroma support.
  5. Configure the app and test one taskKeep save backups before restores or file operations. Network clients need the host/service named by their project. Ports/interpreters require the separately supplied game data named by their card; emulators may also need your own BIOS. Keep each app’s complete companion assets.
  6. Remove an app reversiblyPower off, back up its app folder and move it off the SD card. Disable an unwanted Aroma plugin in its configuration menu before moving its WPS off the card. Keep shared WMS dependencies needed by other plugins and retain save/configuration folders. For themes, use the separate theme recovery instructions.

Choose the correct Wii U format

FormatInstallation
WUHBWii U Homebrew Bundle for supported Aroma home-menu launching. It can contain its executable and app resources in one file. Put it under sd:/wiiu/apps/ at the documented path.
RPX / ELFWii U executables. Some RPX builds support Aroma; others and legacy ELF homebrew need Tiramisu/Homebrew Launcher. Check the specific build, rather than assuming every RPX is compatible.
WPS / WMSPlugins and modules, not app-menu executables. Preserve the complete package layout under /wiiu/environments/aroma/plugins/ and modules/. Inkay’s bundle here includes both.
SD ZIPExtract the required app files to their documented folders. Most store bundles mirror the SD-root layout; FTPiiU’s official release ZIP is flat, so its WPS must be copied into the plugin folder explicitly.
Wii / vWii DOLRuns in the separate Wii environment. Follow the vWii guide before adding those apps; continue to the Wii resources for Wii-format tools.
Source / PC helperSource archives require building, and desktop/mobile binaries run on another device. The downloads here are Wii U console builds, not a PC Wii U emulator.

Verification & project sources

The store packages were checked against their captured hashes, ZIP paths and CRCs. WUHB and PowerPC executable headers were inspected, and original ZIPs were retained with their complete folder layouts. These file checks do not establish physical-console compatibility; no downloaded build was executed.

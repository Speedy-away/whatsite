The official native Vita emulator for Game Boy, Game Boy Color and Game Boy Advance.

Official Vita homebrew build; no exact firmware minimum or handheld model restriction published.
Before installing
Homebrew access, VitaShell and your own game backups. External BIOS is optional.
Game data
Emulator only · bring your own games
Setup & storage paths
  1. Install the ready VPK extracted unchanged from the official Vita 7z, or unpack the original archive on your computer.
  2. Copy your own GB/GBC/GBA backups to a folder you choose, for example ux0:roms/gba/, then select them in mGBA's file browser.
  3. The suggested ROM folder is for organization; upstream does not require that exact location.

Native Nintendo 64 emulation with vitaGL rendering and a per-game compatibility database.

Compatibility
Author explicitly targets Vita / PS TV. Performance and compatibility vary by game.
Before installing
Homebrew access, VitaShell, matching data ZIP and libshacccg.suprx for the renderer. Bring your own ROMs.
Game data
Emulator only · bring your own games
Setup & storage paths
  1. Install DaedalusX64.vpk. Extract the matching ZIP into ux0:data/; its top-level DaedalusX64 folder must become ux0:data/DaedalusX64/.
  2. Confirm libshacccg.suprx exists at ur0:data/libshacccg.suprx or ur0:data/external/libshacccg.suprx. This shader compiler is required by the pinned native build and is not bundled here.
  3. Put your own N64 ROMs in ux0:data/DaedalusX64/Roms/. Check the compatibility list for each game.
  4. The upstream Nightly identifies build 2026-10-12, commit fb7238e. These files preserve the snapshot retrieved on 2 November 2026, with individual SHA-256 hashes.

Install & storage paths

  1. Prepare your model and firmwareUse the existing Vita jailbreak and CFW guides first. Do not change firmware just to match a download. Numeric support is listed only where the author provides it. Vita 1000 needs usable memory-card storage; Vita 2000 and PS TV have internal storage.
  2. Move a VPK using VitaShellUse VitaShell USB or FTP from your computer. ux0: is the active user-storage mount, whether it is an official card, internal storage or correctly configured SD2Vita. A folder such as ux0:downloads/ is a suggested transfer location.
  3. Install the package, then add its dataOpen the VPK in VitaShell and complete the installation prompts. Data ZIPs are not installable VPKs: extract each one at the specific destination on its card, preserving folder names.
  4. Add plugins to the active tai configurationBack up the active config before editing. Kernel SKPRX entries use *KERNEL; shell/user SUPRX entries use their author-specified section. ur0:tai/config.txt is the normal location on this site’s Ensō setup. If ux0:tai/config.txt is active, use its folder and paths consistently. Restart after a plugin change.

Compatibility stays specific. PSVshell and reVita list 3.60 / 3.65; that does not establish support for the other apps. Entries without an author-published firmware range say so. Package checks establish file structure, not hardware performance.

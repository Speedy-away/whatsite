Theme manager

Imago

1.3.0
  • Native Vita
  • VPK
  • Themes

Browse, install and customize Vita themes, then restyle app bubbles and LiveArea artwork.

Compatibility
HENkaku / h-encore / Ensō Vita. Author has not tried PS TV.
Before installing
Enable unsafe homebrew for database writes; internet for browsing the theme repository.
Game data
Theme downloads selected inside the app
Setup & storage paths
  1. Install imago-v1.3.0.vpk using VitaShell and enable unsafe homebrew in HENkaku Settings.
  2. Browse psvt.ovh through Imago, install a theme, then apply it in Settings → Theme & Background → Theme.
  3. Keep the automatic database and original-artwork backups. Local themes need a folder such as ux0:customtheme/YourTheme/theme.xml.

Custom theme · XML assets

MINIMAL

01.00
  • Native Vita
  • ZIP
  • Themes

A cream and black abstract theme with warped patterns and an optical illusion skull lock screen, created by Alberto Munguia.

Compatibility
Custom themes on a homebrew-enabled Vita. No exact firmware range or PS TV claim published by this author.
Before installing
Imago or Custom Themes Manager with unsafe homebrew enabled. This ZIP contains theme assets, not an installable VPK.
Game data
Complete theme assets supplied
Setup & storage paths
  1. Create a new MINIMAL folder beneath ux0:customtheme/. Extract this ZIP into that folder; theme.xml must be directly at ux0:customtheme/MINIMAL/theme.xml. The upstream ZIP has its files at archive root.
  2. In Imago, add the local theme folder to your Library, or use Custom Themes Manager’s local-folder install option. Keep the existing theme database backup.
  3. Apply MINIMAL in Settings → Theme & Background → Theme. Author and version are verified from the original theme.xml.

Install & storage paths

  1. Prepare your model and firmwareUse the existing Vita jailbreak and CFW guides first. Do not change firmware just to match a download. Numeric support is listed only where the author provides it. Vita 1000 needs usable memory-card storage; Vita 2000 and PS TV have internal storage.
  2. Move a VPK using VitaShellUse VitaShell USB or FTP from your computer. ux0: is the active user-storage mount, whether it is an official card, internal storage or correctly configured SD2Vita. A folder such as ux0:downloads/ is a suggested transfer location.
  3. Install the package, then add its dataOpen the VPK in VitaShell and complete the installation prompts. Data ZIPs are not installable VPKs: extract each one at the specific destination on its card, preserving folder names.
  4. Add plugins to the active tai configurationBack up the active config before editing. Kernel SKPRX entries use *KERNEL; shell/user SUPRX entries use their author-specified section. ur0:tai/config.txt is the normal location on this site’s Ensō setup. If ux0:tai/config.txt is active, use its folder and paths consistently. Restart after a plugin change.

Compatibility stays specific. PSVshell and reVita list 3.60 / 3.65; that does not establish support for the other apps. Entries without an author-published firmware range say so. Package checks establish file structure, not hardware performance.

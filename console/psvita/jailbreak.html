Check your firmware & storage

Find the installed firmware in Settings > System > System Information. The HENlo host lists 3.65–3.74; use the maintained guide’s firmware selector to confirm the route for your exact version. Keep the Vita charged and connected to the internet.

Vita 1000 without an official memory card: follow the separate internal-memory-card procedure before continuing. It includes storage changes and a system restore, so back up first. Vita 2000 and PS TV have internal storage available for the normal route.

Open the HENlo browser host

HENlo host: https://jailbreak.psp2.dev/

Use http://jailbreak.psp2.dev in the Vita browser, as shown by the maintained guide. The HTTPS link above can be opened on a computer or phone.

  1. Prepare the browserFollowing the video, allow cookies and enable JavaScript in the browser settings. Its preparation also clears cookies and search history before loading the host.
  2. Enter the addressType the host into the Vita browser’s address bar. Check that the hostname is jailbreak.psp2.dev.
  3. Start HENloChoose Unlock my Vita, then Unlock. Wait for the henlo-bootstrap menu to appear.
  4. Install the homebrew componentsChoose Install henkaku, then Install VitaDeploy. When both complete, choose Exit.
  5. Enable homebrew in SettingsOpen Settings > HENkaku Settings and enable Enable Unsafe Homebrew. Confirm VitaDeploy is now available in LiveArea.

Continue to persistent homebrew

HENkaku enables homebrew in the current session. VitaDeploy is the installation toolbox. Ensō adds boot-time persistence; the next guide uses VitaDeploy’s documented firmware 3.65 preset.

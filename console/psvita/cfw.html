PS Vita CFW & Ensō Setup

Install persistent Vita homebrew with VitaDeploy’s 3.65 preset, then configure iTLS, update settings and optional SD2Vita storage.

Start with HENkaku & VitaDeploy

Complete the HENlo guide first and enable Unsafe Homebrew. This route installs firmware 3.65 with HENkaku Ensō so homebrew starts after a reboot. Connect to the internet and keep the console powered throughout the installation.

Install firmware 3.65 & Ensō

  1. Open VitaDeployFrom LiveArea, launch VitaDeploy and choose Install a different OS.
  2. Choose Quick 3.65 InstallSelect the quick preset and let it download and prepare the required components.
  3. Read and confirmWhen prompted, press Cross (X), read the installation notice and wait through its countdown before confirming. Stop if the displayed firmware or operation differs from the documented route.
  4. Let the installation finishLeave the Vita powered on while the firmware installs. It reboots when the process completes.
  5. Handle the memory-card prompt carefullyIf the reboot asks to transfer internal-memory-card data to a removable card, choose No. The maintained guide warns that choosing Yes deletes data on the removable card.

PS Vita firmware archive

Darthsternie’s archive lists normal, preinstalled and systemdata firmware packages with version numbers, file sizes and MD5 hashes. Choose the package type and version required by your setup guide.

These are system-software files. For HENkaku and persistent homebrew, follow the separate jailbreak and Ensō guides; the setup on this site remains pinned to VitaDeploy’s Quick 3.65 Install.

Finish the system setup

  1. Download iTLS InstallerOpen VitaDeploy > App downloader, select iTLS Installer, then Download the selected apps.
  2. Install iTLS for EnsōOpen iTLS-Enso and select Install the full iTLS package, then reboot when asked. The full package is for an Ensō system; other configurations use the project’s separate instructions.
  3. Disable automatic system-update downloadsIn Settings > System > Auto-Start Settings, turn off Download Update File for System Software.
  4. Review HENkaku spoofing settingsIn Settings > HENkaku Settings, enable Enable PSN Spoofing and Enable Version Spoofing. The checked guide sets the spoofed version to 3.74; use its current value if those instructions change. This changes the reported version, not the installed firmware.

Optional SD2Vita storage

SD2Vita is a microSD adapter for the Vita game-card slot. YAMT requires Ensō on firmware 3.60 or 3.65 and is included in VitaDeploy’s Quick 3.65 Install. Follow the complete storage guide before changing mounts; formatting erases the selected storage.

Install and prepare

Start on a Vita that already runs homebrew. Get the Vita VPK from the site’s Save Tools page, transfer it with VitaShell and open the VPK in VitaShell to install it. Launch Apollo from LiveArea so it can detect the Vita’s user and Account ID.

What does “switch the PSN ID” mean?

For a save, this usually means resigning it for the account that will load it. The save’s owner is separate from your public PSN username.

PSN Online ID
Your visible username. Typing a different username into a save folder does not transfer ownership.
Account ID
The account identifier recorded in save metadata. Apollo displays it as 16 hexadecimal characters, for example 0123456789abcdef. Use the destination account’s real value.
Local User ID
A user number on this console. It is separate from the Account ID and can differ on another console.
Game / title ID
For example PCSE00019 for the US edition of Dragon’s Crown. This identifies the game build or edition; it is not an account.

Keep an untouched backup of both the source save and the destination account’s existing save. Changing ownership does not make a save compatible with another game, edition, update or platform.

1. Back up your Vita save

  1. Close the gameReturn to LiveArea and close the game so it cannot write to the save while Apollo copies it.
  2. Select the installed saveOpen the internal save list in Apollo. Highlight the game and use View Save Details or Triangle to confirm its title ID and slot.
  3. Copy the whole saveOpen Copy save game → Copy Save to Backup Storage. Choose the storage mount and record the folder shown by Apollo. Keep the full folder, including sce_sys, and transfer an untouched copy to your computer with VitaShell.

2. Assign the save to the receiving Vita

  1. Prepare the receiving consoleUse the Vita that will run the game. Open the matching edition, create an ordinary save, then close the game. Back up that save before copying anything over it.
  2. Check the destination Account IDOn that Vita, open About in Apollo and check the 16-character Account ID it detected. View Save Details on the imported copy to see the owner recorded in the save.
  3. Resign the backup copyOpen the external or backup save list and select the matching decrypted Vita save. Choose Apply Changes & Resign without selecting any gameplay patches. Apollo writes the receiving Vita’s detected identity to the save metadata. If Apollo reports an account error, stop and check the save before restoring.
  4. Check the resultOpen View Save Details again and compare the save’s Account ID with About. When they match, restore the copy using the next section.

For a transfer between two accounts, do the resigning on the destination Vita. Your public PSN name stays the same. An all-zero value in About is not a verified match for a specific PSN account.

3. Import or restore a Vita save

  1. Stage a decrypted copyExtract a compatible save archive and place the intact save folder under the selected mount’s data/savegames directory. For a community save, you can also use Online DB → the matching title → Download to Backup Storage, then return to the backup save list.
  2. Back up the destination slotCheck that the matching game has created a save and that you have a separate copy of it. Copying into user storage can overwrite files for that title.
  3. Restore from ApolloSelect the prepared copy in the backup save list. Choose Copy save game → Copy Save to User Storage (ux0:user/). Open the game and verify the expected progress. Keep both originals until it works.

For an existing backup that already belongs to this Vita’s account, check its details and restore it directly. Use the ownership step above when the saved Account ID differs.

Save folder layout

Example decrypted Vita backup on ux0

ux0:data/savegames/
└── PCSE00019/
    ├── sce_sys/
    │   └── param.sfo
    └── <the game’s save files>

Keep the folder name and layout created by Apollo. This is one title-ID example. Depending on your storage configuration, backup storage may use uma0:, imc0:, xmc0: or ux0:. Installed Vita saves live under ux0:user/00/savedata/. Restore through Apollo so it can mount the destination save.

PSP and PS1 saves in Adrenaline

PSP games

Adrenaline normally reads PSP saves from ux0:pspemu/PSP/SAVEDATA/. If your Adrenaline setup uses another memory-stick location, verify which mount the game actually reads. Back up the whole PSP save folder. For PSP resigning, follow Apollo’s documented FuseID setup. Decrypting or patching a PSP save can also require that game’s save key.

PS1 memory cards

Keep an untouched copy of the virtual memory card before editing it. Apollo scans external card images under data/PS1/VMC/ on the selected mount and can import individual saves from data/PS1/SAVEDATA/. Use the memory-card tools for your format and confirm that the game is using the card you edited.

Official PSP save requirements

Apply a supported save patch

Keep an untouched backup. Open the save for the exact game and title ID, select the relevant patch, then choose Apply Changes & Resign. Read any required companion patch in the list and test the result in the game before making another change.

Troubleshooting

The backup does not appear.

Check the selected storage mount. Extract ZIP files and put the actual save folder directly inside data/savegames. Keep sce_sys and the payload together, then press Square to refresh the list.

Copying to user storage fails.

Make a save in the matching game on the receiving Vita first, close the game and check the title ID. If Apollo still cannot mount it, keep your backups and check the project’s release notes before replacing any files.

The game cannot read the save.

Check the title ID, edition, update and any required DLC. Confirm the copy is a decrypted Vita save and check its Account ID after resigning. Restore the untouched backup if the replacement fails.

Can I move progress between different game editions or consoles?

Check the game’s own save compatibility. Resigning changes ownership metadata. Progress stored on a game server follows that game’s account system.

Load a saved BIN with Payload Guest

  1. Start your supported homebrew environmentPayload Guest requires an already working compatible PS4 HEN or GoldHEN environment. It does not supply the initial exploit or establish support for every firmware.
  2. Install the existing Payload Guest packageUse the pinned v0.98 package on the Apps page with your compatible console package installer. Downloading its PKG does not install it.
  3. Place the compatible BIN fileTransfer your payload to /data/payloads/, or put it in the payloads folder on an actually mounted USB filesystem. Downloading a ZIP/RAR does not extract its BIN.
  4. Open Payload Guest and choose the payloadLaunch Payload Guest on the PS4 and explicitly select the compatible BIN. Square refreshes the list after USB insertion or removal. A meta.json catalogue in a folder overrides that folder’s automatic BIN scan.

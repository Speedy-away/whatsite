DNS settings & online play

Primary DNS from the video
45.56.67.85
Alternate primary DNS
62.210.38.117

The video presents these as alternative primary DNS choices for update blocking. If DNS breaks ordinary internet access, it demonstrates Easy/Automatic network setup, with the consequence that this DNS blocking is removed. Keep the shared site's PSN/online-risk notice with this section.

Sony / PlayStation server blocking: These DNS servers are intended to block PlayStation update servers and can also restrict PSN sign-in and other Sony services. DNS blocking is not a guarantee that every Sony server is blocked.

For normal online play: Do not use these blocking DNS settings. Set DNS Settings → Automatic, or restore your usual DNS. This can also allow update connections again.

Jailbreak online risk: Using a jailbroken console on PlayStation Network risks a console ban, account ban, or both. Changing DNS does not make online jailbreak use safe or bypass PSN’s software and account requirements.

Browser jailbreak · step by step

  1. Check downloads and disable automatic updatesWatch update preparation
    Open Notifications → Downloads and check for a pending system-software update. The video removes a queued update before continuing. In Settings → Network, temporarily turn off Connect to the Internet. Then open Settings → System → Automatic Downloads and disable the automatic-download options shown in the tutorial.
  2. Confirm your installed firmwarewhatwhatboy’s PS4 host
    Read Settings → System → System Information. This tutorial demonstrates 13.52 and describes the browser route from 7.00 through 13.52. Stay on an already supported version; the optional update video is not a requirement. Use a separate compatible route for older firmware, and the separate guide for 14.00.
  3. Prepare the network connectionWatch network setup
    Re-enable Connect to the Internet and choose Set Up Internet Connection. Select Wi-Fi or LAN Cable, then Custom. Keep IP settings appropriate for your network, use Do Not Specify for DHCP on a typical setup, and choose Manual DNS. The video supplies 45.56.67.85 with 62.210.38.117 as an alternate primary resolver. Finish with the normal MTU and proxy settings, then test ordinary browsing. Automatic/Easy settings remove this DNS blocking if the resolver prevents a connection.
  4. Clear the browser before the first setupWatch browser preparation
    In Internet Browser, use Options to remove frequently used pages. Open Settings and delete cookies and website data. Clear Browsing History as shown, then close and reopen the browser. Do this during initial setup or documented troubleshooting; clearing website data later can remove the offline cache.
  5. Open and cache the matching hostwhatwhatboy’s PS4 host whatwhatboy’s PS4 host
    Open https://speedy-away.github.io/hosts/ps4/ in the PS4 browser and select your exact installed firmware. Choose the compatible browser entry and follow its displayed loading and cache instructions. Bookmark the selected entry if it supports offline use; cache preparation and restart steps depend on that build. This guide page is separate from the exploit host.
  6. Wait for GoldHEN and confirm successWatch loading and recovery
    After reopening the cached host, let its compatible jailbreak chain finish. Confirm the GoldHEN notification and settings appear before installing homebrew. A memory error may require dismissing the message and retrying as shown; a failure or system crash may require a restart. Follow the host's current recovery prompts, and do not keep retriggering a host once GoldHEN is already active.
  7. Use the cached host offlineWatch offline use
    Once caching has completed, the video demonstrates loading the bookmarked page with Connect to the Internet disabled. Keep the cached browser data if you want this offline route. Do not launch the exploit again merely to test the cache while your current GoldHEN session is already running. Reconnect only when a task needs network access.
  8. Configure the GoldHEN features you needWatch GoldHEN settings GoldHEN features and documentation
    Open GoldHEN settings. Debug Settings contains Package Installer; Cheat Settings and Plugin Settings provide archive updates. The video also shows the FPS overlay, FTP and payload-server settings, local/USB payload loading and date/time synchronization. GoldHEN documents an update-blocking feature, but keep the preparation settings in place instead of treating it as a guarantee against every update or PSN connection.
  9. Install compatible homebrew packagesPS4 apps and packages On-console downloads Watch package installation
    For the USB method shown, copy the PS4 PKG files to the root of an exFAT or FAT32 USB drive, connect it to the PS4, then open GoldHEN → Debug Settings → Package Installer. Select the intended homebrew package or the documented Install All option. Homebrew Store can then install more supported homebrew on the console. Archives and ELF/BIN payloads need their own loading or extraction steps; they are not USB PKG installs.
  10. Finish patch or plugin setup only when neededWatch patches and plugins Game-specific mod instructions
    The video demonstrates updating cheats, patches and plugins through GoldHEN, with PS4 Cheats Manager as a fallback if an archive update fails. Match any patch or plugin to the game's title ID and update. Enable the plugin loader and game-patch plugin only after installing the matching components; a downloaded mod file alone is not a completed installation.
  11. Reload the jailbreak after a restartWatch restarting and reloading
    A full restart ends the active jailbreak session. Installed homebrew and downloaded files remain on storage, but their launch may be restricted until you reopen the bookmarked compatible host and GoldHEN loads again. The video also discusses Rest Mode; its behavior is specific to the exploit and payload build rather than a permanent CFW guarantee.

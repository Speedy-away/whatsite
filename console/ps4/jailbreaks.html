PS4 Jailbreak · 14.02 or Lower

Before you start

This guide follows MODDED WARFARE’s 10 November 2026 PS4 tutorial. WWB Host provides the demonstrated GamerHack browser route for supported 7.00–14.00 firmware with GoldHEN 2.4b18.13.

  • A PS4 with a supported installed firmware and its controller.
  • An internet connection for the first cache installation.
  • A computer and USB drive only if you choose a firmware update or USB app installation.

Keep your installed firmware while checking support. Open Settings → System → System Information. This guide covers 14.02 or lower. Check the host’s exact firmware list before proceeding; the demonstrated route below lists support through 14.00. For older firmware, check the WWB Host firmware selector for a separate compatible route.

Run the browser jailbreak

Follow these steps in order. The browser host supplies the compatible payload, so this guide does not require a separate GoldHEN or HEN download.

  1. 1. Disconnect and turn off automatic downloadsIn Settings → Network, temporarily uncheck Connect to the Internet. Then open Settings → System → Automatic Downloads and turn off the automatic-download options. This gives you time to check the installed version before reconnecting.
  2. 2. Confirm the firmwareUse Settings → System → System Information. If your version is supported, keep it and continue. Updating to 14.00 is optional; read the compact firmware section below before changing anything. A USB update is not a downgrade method.
  3. 3. Set up the internet connectionReconnect through Settings → Network → Set Up Internet Connection. Choose Wi-Fi or LAN and select Easy for a standard home connection.
  4. 4. Leave DNS on AutomaticWWB Host works with your normal internet connection. Custom DNS is optional. If you previously set a DNS that blocks PlayStation services, switch back to Automatic before trying PSN.
  5. 5. Check the connectionOpen the PS4 Internet Browser and check that an ordinary website loads. Keep automatic downloads disabled while setting up the guide.
  6. 6. Prepare the browser onceBefore the first cache installation, clear frequently used pages and browsing history through Options. In browser Settings, delete cookies and clear website data. Close the browser with Circle and open it again. Skip this cleanup on later launches so you retain the offline cache.
  7. 7. Open WWB HostEnter the address below in the PS4 browser and bookmark the host page. Check the supported firmware list, then follow the offline cache link and wait for Cache ready. https://speedy-away.github.io/hosts/ps4/exploit/gamerhack-g2all/
  8. 8. Close, reopen and waitClose the browser and reopen the bookmarked host. Follow the on-screen confirmation for your installed firmware, then wait for the GoldHEN notification and settings menu.
  9. 9. Handle a failed attemptIf the console reports insufficient free system memory, dismiss the message and allow the host to retry. If the host requests a reboot or the console shuts off, restart it and reopen the cached host. Read the displayed failure message before retrying.
  10. 10. Confirm the session is readyReturn to the PS4 function menu and open GoldHEN. A saved bookmark or downloaded file alone does not confirm success. Continue to app installation only after GoldHEN has loaded.

PSN and online play

You can try signing in with Automatic DNS if your system software meets PlayStation’s requirements. Play online with a modified console at your own risk. PlayStation may suspend your account or console.

PSN may require a system update. Check the version before accepting an update because newer firmware can remove jailbreak compatibility.

Use it offline and reload after a restart

After the first successful cache installation, disconnect in Settings → Network and reopen the same bookmark to check offline access. Keep cookies and website data intact. Clearing the browser cache means you must reconnect and install the cache again.

A full shutdown or restart ends the active jailbreak session. Your installed apps and files stay on storage, but some apps show a padlock until you reopen the cached host and GoldHEN loads again. Rest Mode can retain a session; reliability depends on the firmware and payload build. A cold start followed by the browser route is the recovery path if it fails.

Install homebrew apps from USB

  1. Prepare the storageUse an exFAT USB drive where possible, or FAT32 for files small enough for its 4 GB per-file limit. Back up the drive before any optional formatting.
  2. Copy the app packagePlace a trusted PS4 homebrew .pkg file in the root of the USB drive, outside other folders. Safely eject the drive and connect it to the PS4.
  3. Install through GoldHENWith GoldHEN running, open GoldHEN → Debug Settings → Package Installer. Select the app package, wait for installation and launch its new home-screen tile. Match the app’s own firmware requirements.

Optional GoldHEN settings

The core jailbreak is ready once GoldHEN loads. The video then demonstrates settings you can enable when you need them:

  • Cheats and patches: update the cheat and patch archives from their GoldHEN menus. A patch must match the game, title ID and installed update.
  • Plugins: update the plugin archive, then enable the plugin loader and game-patch plugin for compatible patches. The video uses PS4 Cheats Manager as a fallback if the built-in plugin update fails.
  • Overlays: choose FPS or system-information displays and their position in Game Overlay Settings.
  • File transfer: enable the FTP server only when you want to transfer files on your own local network.

Launch a game after enabling its patches. Hold Share for the cheat menu, or use the game tile’s Options → GoldHEN Cheat Menu. Disable active cheats before switching between different cheat sets. Some features depend on the exact app, game update and GoldHEN build.

Troubleshooting

The host says the firmware is unsupported

Recheck System Information and the exact host address. This route covers supported 7.00–14.00 firmware. Use the WWB Host firmware selector to check for a separate route for your installed version.

The cache does not work offline

Reconnect and revisit the exact bookmark. Let caching finish before closing the browser. If the cache installation itself is broken, clear the browser data once and repeat the first setup. That cleanup removes the old cache.

The browser reports a memory error

Dismiss the ordinary memory message and let the host retry. For a reboot request or console crash, restart first. Repeated failures can depend on the exploit build; check the host’s instructions.

Apps show a padlock after restarting

Reload GoldHEN through the cached browser host. Installed apps remain on storage; reinstalling everything is not normally the first step.

A USB app package is missing

Check the drive format, put the PS4 .pkg in the USB root and make sure GoldHEN is running. An archive must be extracted to its ready-to-install package first.

Set manual DNS on PS4

Primary DNS
45.56.67.85
Secondary DNS
62.210.38.117

Sony / PlayStation server blocking: These DNS servers are intended to block PlayStation update servers and can also restrict PSN sign-in and other Sony services. DNS blocking is not a guarantee that every Sony server is blocked.

For normal online play: Do not use these blocking DNS settings. Set DNS Settings → Automatic, or restore your usual DNS. This can also allow update connections again.

Jailbreak online risk: Using a jailbroken console on PlayStation Network risks a console ban, account ban, or both. Changing DNS does not make online jailbreak use safe or bypass PSN’s software and account requirements.

PlayStation account & console suspensions
  1. Open the network wizardGo to Settings > Network > Set Up Internet Connection. Choose Use Wi-Fi or Use a LAN Cable, then Custom.
  2. Keep your normal IP settingsUse your existing IP and DHCP configuration. For a typical home network these are Automatic and Do Not Specify.
  3. Set DNS to ManualPrimary DNS: 45.56.67.85. Secondary DNS: 62.210.38.117.
  4. Finish setupKeep the normal MTU and proxy settings; a typical network uses Automatic and Do Not Use. Save and test the connection. You can restore DNS to Automatic later.

Blu-ray method: preparation & flow

  1. Check your firmware and equipmentRead Settings > System > System Information. Confirm the video applies to that exact firmware. Prepare a computer, Blu-ray writer and blank supported BD-R/BD-RE media.
  2. Get the supplied HEN ISODownload GOLDHEN14.iso Supplied HEN ISO
    Download the ISO using the links here. If the supplied file is an archive, extract it first. Check the video’s current notes and any published checksum before using the ISO.
  3. Burn the image to Blu-rayImgBurn downloads
    In ImgBurn choose Write image file to disc, select the ISO and the Blu-ray writer, and burn to the blank disc. Enable verification and let it complete. Copying the ISO as a normal data file does not create the same disc.
  4. Start the disc on PS414.00 disc workflow reference
    Insert the finished disc and open its disc/Blu-ray tile. The documented 14.00 disc waits for one Cross (X) press after validation. Follow the instructions shown by the actual image you burned.
  5. Confirm HEN successCheck that the HEN features actually work before installing homebrew. After a failure, shut down completely and cold-boot before another attempt; do not repeatedly trigger it in the same session.

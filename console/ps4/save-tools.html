Import a save with Apollo

  1. Back up your current save. Keep a separate copy of your own save before importing community data.
  2. Find the matching save in Apollo. On a homebrew-enabled PS4, open Apollo Save Tool, choose Online Database and select the matching game and save. Download to the internal drive or a USB drive.
  3. Check the imported save. For an internal download, check HDD Saves. For a USB download, open USB Saves and use Copy save game to transfer it to the internal drive.

If you downloaded a ZIP from this page, extract it first. Keep each save folder and its sce_sys contents together, then follow Apollo’s guide for importing decrypted saves from USB.

Add the PS4 site bookmark

The original whatwhatboy icon is included in the PS5 shortcut package. The bookmark route on PS4 uses the console’s Internet Browser tile.

  1. Open Internet Browser from the content areaOn the PS4 home screen choose Internet Browser. Press Triangle to enter a URL.
  2. Open the PS4 hubEnter https://whatwhatboy.com/console/ps4/. The Downloads navigation stays within PS4 resources.
  3. Save the bookmarkWhile viewing the hub, press OPTIONS and select Add Bookmark. Name it whatwhatboy PS4.
  4. Return from HomeOpen the Internet Browser tile, press OPTIONS, choose Bookmarks and select whatwhatboy PS4. Frequently Used Pages is another browser shortcut.

This is the PS4 browser’s supported bookmark workflow. It does not install a separate whatwhatboy PKG or replace the browser’s home-screen icon. A browser bookmark gives no additional storage permissions.

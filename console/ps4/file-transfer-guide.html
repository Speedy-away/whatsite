How do you want to transfer files?

↗FTP · computer or phoneUse your local network. No USB drive needed.⇅USB · copy from a driveUse a USB drive and the console file manager.

Before you start

FTP and these file managers need an already compatible homebrew setup. Check your exact console firmware first. A normal retail console does not provide this FTP access.

Find your console IP address

For FTP, connect both devices to the same local network. Keep the console awake and its FTP service running. A wired console connection can help with large files.

  1. Settings
  2. Network
  3. View Connection Status
  4. IP Address

Write down the console’s IPv4 address and FTP port. Use the console address, not your phone’s address or your router’s address. The address in the picture is only an example.

PS4 · start the FTP server

With your compatible GoldHEN setup active, open GoldHEN settings, open Server Settings and enable the FTP server. GoldHEN normally uses port 2121. If you use another server, use its displayed port and login details.

Your FTP connection

Host / address

FTP · plain FTP when encryption is unsupported

Use the login details required by your running FTP server.

Plain FTP is unencrypted. Use your own trusted local network and turn the server off when you finish. Do not forward the FTP port on your router.

What will you use for FTP?

Use a computerUse a phone

Use FileZilla on a computer

Install FileZilla Client on Windows, macOS or Linux. The console runs the FTP server.

Download FileZilla Client
  1. Connect to your consoleOpen File → Site Manager → New site. Choose FTP. Enter your console IP and port. If the server has no TLS support, choose Only use plain FTP. For servers with anonymous access, choose Anonymous; otherwise use the login required by your server. Select Connect.
  2. Choose your files and destinationThe left pane is your computer. The right pane is your console. On the left, find your completed download. On the right, open the folder required by that file’s installation guide. For a simple transfer test, use a new folder inside /data.
  3. Upload a copyDrag the file from the left pane to the right pane, or right-click it and choose Upload. To copy a file back to your computer, use Download on the console side. If a file already exists, skip it or choose a new name until you have checked it.
  4. Check that the transfer finishedWait for the queue to finish. Check Failed transfers, then refresh the destination and compare the filename and size. Keep your original copy. If the connection drops, check the partial file before resuming or retrying.

Use FTP from your phone

Download the file to your phone first. Then open an FTP client and upload it to the console. An FTP server app on your phone is a different tool.

Which phone do you use?

iPhone / iPadAndroidHarmonyOS

iPhone & iPad

Get FTPManager · App Store

In FTPManager, add an FTP connection using the console IP, port and server login. Allow Local Network access if iOS asks. Open the completed download in Files and use Share to copy it into FTPManager if needed. In the app, copy or upload the local file to the console folder.

Android

Get Solid Explorer · Google Play

In Solid Explorer, add a storage connection and choose FTP. Enter the console IP, port and server login. Open Downloads, select the completed file and choose Copy. Open the console connection, enter the destination folder and choose Paste. Allow access to the local file when asked.

HarmonyOS · Huawei

Get electerm · AppGallery

electerm has a native HarmonyOS app with FTP support. Add an FTP connection, enter the console IP, port and server login, then upload a local file to the destination. App availability and controls can vary by region and release.

HarmonyOS NEXT needs a native compatible app. Older Huawei phones that support Android apps may use a compatible Android FTP client. Check your device and store listing before installing; an Android APK is not a native HarmonyOS NEXT app.

Keep the FTP app open until the upload finishes. Refresh the console folder and compare the file size. If the app cannot see the download, import it from Files or Downloads and retry.

Help saving files on a phone

Copy from a USB drive

  1. Prepare an ordinary USB driveUse a drive readable by your file manager. exFAT is usually the practical choice for large files; FAT32 has a single-file limit of just under 4 GiB. Formatting erases the drive, so copy anything you need elsewhere first. A drive formatted as PlayStation extended storage is not an ordinary transfer drive.
  2. Copy your completed filesOn your computer or compatible phone with a USB adapter, copy the file into a clearly named folder on the USB drive. Wait for copying to finish, safely eject it, then connect it to the console.
  3. Open the real USB mountOpen your console file manager and look under /mnt for the mounted USB drive. Names such as /mnt/usb0 and /mnt/usb1 are examples, not fixed USB socket numbers. Find your folder and check the filename.
  4. Copy and verifySelect the file or folder, choose Copy, open the required internal destination and choose Paste. Wait for completion and compare the file size. Keep the USB original until you have checked the copy. Copying a file does not install or run it.

PS4 file management · PS4-Xplorer

Use the existing PS4-Xplorer 2.07 listing for PS4. Install its PS4 PKG with your compatible package installer, then start PS4-Xplorer from the console home screen.

Get PS4-Xplorer · PS4 apps

In PS4-Xplorer, Cross opens or confirms, Circle goes back, and Triangle opens the action menu for Copy or Paste. Follow the hints in your installed version if its controls differ.

Browse to the source file, open the app’s action menu and choose Copy. Browse to the destination and choose Paste. Use New folder when you need a separate destination. Read the control hints in your installed version; button mappings and modes can differ.

Use Copy for your first transfer. Back up an existing destination before replacing anything. Do not change system folders or permissions unless the file’s own instructions require it. Saved games need the matching save-management tool.

Where should the file go?

There is no single destination for every download. A plugin, save, package and payload each have their own setup. Follow the exact platform, firmware, game update and folder instructions on the download’s page.

A PKG must still be installed with a compatible installer. A ZIP must be extracted when the instructions say so. A BIN or ELF needs its matching loader. Renaming a file does not convert it.

If something does not work

If something does not work

Cannot connect? Check the console IP, same network, active FTP service and its exact port. Guest Wi-Fi, VPNs and router device isolation can block local connections. Allow the FTP client through your computer firewall.

Login or encryption error? Check the server’s authentication and TLS support. Do not use SFTP for an FTP-only server. A web file manager on port 8080 is not the FTP service.

A large file fails on USB? Check free space and the drive format. FAT32 cannot hold a file of 4 GiB or larger. On FTP, inspect failed transfers and keep the console awake.

Cannot see the file? Refresh the folder, check the actual USB mount and confirm the download finished. A downloaded HTML error page is not the intended file.

Understand the hardware target

PS4 baseAn unlocked cap can still hit CPU or GPU limits. Some files offer a separate lower-resolution option. Follow each option’s hardware note.
PS4 ProPro-specific resolution and display options are labelled in the source metadata. Choose the one intended for your hardware and game mode.
PS5PS4 CUSA patches use backward compatibility; native PS5 PPSA patches use the PS5 executable and update. Engine firmware support and game support are separate checks.

A 120Hz output option also needs a compatible display/output mode and a suitable patch engine. It does not prove that a game renders a stable 120 FPS. No physical-console performance measurements were made for this catalogue.

PS4 option: GoldHEN game-patch plugin

Use GoldHEN 2.3 or newer on a firmware supported by that exact GoldHEN release. This route uses a native PS4 PRX plugin and PS4 Cheats Manager. It is separate from the ELF patch-system route below.

  1. Install PS4 Cheats Manager 1.2.2Use its ready PS4 PKG with your existing supported package installer. Downloading the PKG does not install the app.
  2. Configure the game-patch pluginPut game_patch.prx in /data/GoldHEN/plugins/. Merge its line into the matching game’s section in your existing /data/GoldHEN/plugins.ini, and enable plugin loading in GoldHEN. Preserve every existing entry.
  3. Transfer the exact title fileFor example, place the selected CUSA00900.xml at /user/data/GoldHEN/patches/xml/CUSA00900.xml. Create missing folders with your console file manager. A copy in a general downloads folder is not yet installed as patch data.
  4. Choose the exact optionOpen the game’s patch list in PS4 Cheats Manager. Enable only the option matching your title ID, game update and hardware. Fully close and relaunch the game so the patch engine can apply it.

PS4 option: PS Patch System

The project reports a confirmed working firmware range of 9.00–12.52 on PS4. This is the engine’s published tested range, not a guarantee for every game or firmware build. Other PS4 firmware can use the GoldHEN route only when that exact environment supports the plugin.

Use your own USB wallpaper

  1. Prepare the imageUse a JPG or PNG. The official guide supports up to 1920 × 1080 on PS4 or 3840 × 2160 on PS4 Pro. Place it inside an IMAGES folder at the root of a FAT32 or exFAT USB drive.
  2. Open the console’s image pickerInsert the drive, then open Settings > Themes > Select Theme > Custom > Select Image > USB Storage Device. Select and crop the picture.
  3. Apply the backgroundPreview the result and select Apply. The wallpaper route uses an image; a RAR archive or a theme PKG is a different file type.

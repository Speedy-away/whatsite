Before you start

Use Apollo on a homebrew-enabled PS4 with a firmware and homebrew environment supported by your Apollo build. Install the PS4 package; the PS3 package is a separate application.

  • Sign into the local console user that should own the save.
  • Close the game before copying or changing its save.
  • Prepare a readable USB drive with enough free space.
  • Check the save’s title ID, game update, edition and required DLC.
  • Have a real PSN-linked or appropriately offline-activated target profile.

What does “switch the PSN ID” mean?

For a save, this usually means resigning it for the account that will load it. The save’s owner is separate from your public PSN username.

PSN Online ID
Your visible username. Typing a different username into a save folder does not transfer ownership.
Account ID
The account identifier recorded in save metadata. Apollo displays it as 16 hexadecimal characters, for example 0123456789abcdef. Use the destination account’s real value.
Local User ID
A user number on this console. It is separate from the Account ID and can differ on another console.
Game / title ID
For example CUSAxxxxx. This identifies the game build or edition; it is not an account.

Keep an untouched backup of both the source save and the destination account’s existing save. Changing ownership does not make a save compatible with another game, edition, update or platform.

1. Back up your current save

  1. Make a normal console backup when available.In PS4 Settings, open Application Saved Data Management → Saved Data in System Storage → Copy to USB Storage Device. Select the game and save. This produces the encrypted PS4 transfer format.
  2. Make an Apollo working copy.Open HDD Saves, select your game’s save, then choose Copy save game and a USB destination. Apollo copies the save in decrypted form for its own import workflow. Wait for the success message.
  3. Keep the backup separate.Copy the entire exported folder to a PC and label it with the game, account and date. Keep its contents unchanged; work on a second copy.

Two formats, two import routes. A normal PS4 USB export belongs under PS4/SAVEDATA/. Apollo’s decrypted working copies belong under PS4/APOLLO/. Renaming one folder into the other does not convert the save.

2. Check the account that will own the save

If this local user already has the correct PSN Account ID, keep that identity and continue to resigning. Check Apollo’s About screen and View Save Details rather than entering your public username.

Find your own PSN Account ID

On a console where your PSN account is already linked, export one of your PS4 saves using the normal Settings USB backup. On a PC, read the folder immediately after PS4/SAVEDATA/. The 16-character hexadecimal folder name is the Account ID for that export. Preserve any leading zeros.

For an offline profile that needs activation

  1. Back up the profile’s existing saves first.Changing the profile Account ID can leave older saves associated with its previous identity. Record that identity before making a change.
  2. Open the account tools.In Apollo choose User Tools → Activate PS4 Accounts, then carefully select the intended local profile.
  3. Choose the identity you need.For transfer to your own PSN account, replace the proposed value with the exact 16-character Account ID taken from your own PS4 export. A generated offline ID works for a local offline setup but will not match a different real PSN account.
  4. Confirm and reload the user.Accept the on-screen entry and confirmation prompts. Exit Apollo and restart the console when activation reports that a reboot is required. Reopen Apollo and verify the Account ID in About.

Offline activation sets the local profile’s identifier. It does not sign into PSN or rename your PSN Online ID. Do this account setup before importing saves for that identity.

3. Switch the save to your account

For a decrypted Apollo USB copy or a save already on HDD. Make the save belong to the current user, then test one save before changing a batch. An encrypted USB entry with a lock uses the separate import route below.

  1. Open Apollo as the destination user.Confirm that its About screen shows the Account ID you want. Choose USB Saves for a USB copy, or HDD Saves for an existing internal save.
  2. Inspect the save.Use View Save Details and check the game/title ID, save slot and location. If the game or required update differs, stop and resolve that mismatch first.
  3. Apply the ownership change.Choose Apply Changes & Resign and wait for success. With no manual account override, Apollo uses the current user’s configured Account ID. The USB bulk menu also offers Resign selected Saves; leave batch actions until a single save has worked.
  4. Copy the prepared USB save to the console.Choose Copy save game → HDD for the prepared USB save. Read any overwrite prompt carefully and preserve your existing slot backup.
  5. Check it inside the game.Exit Apollo cleanly, start the matching game under the same user, load the intended slot and verify progress. Make a fresh backup once it works.

Why there is no PS4 Change Account ID menu here

The PS3 SFO Patches → Change Account ID instructions do not apply to the current PS4 menu. For PS4, use the intended destination profile, check its Account ID, and resign with that configured identity. Older screenshots may show a Save Data Owner setting that is absent from the current source. Follow the destination-user workflow for the current build rather than looking for that historical setting.

4. Import, restore or move a save

A decrypted community save from a ZIP

  1. Extract the archive on your computer.Keep the save payload and its sce_sys folder together. Preserve the supplied save folder name and title ID. Avoid an extra ZIP-name folder around the actual save.
  2. Use the Apollo folder layout.Place the complete save folder under PS4/APOLLO on the USB drive. Open USB Saves, inspect the save, resign it for the target user, then use Copy save game to copy it to HDD.
  3. Or download inside Apollo.Choose Online DB, select the exact matching game and save, then use the displayed destination. Check HDD Saves for an internal download; for a USB download, return to USB Saves and copy the save to HDD. Verify the resulting owner and game slot.

An encrypted PS4 USB export

Keep the complete container and matching .bin companion in their original PS4/SAVEDATA/<ACCOUNT-ID>/<TITLE-ID>/ structure. In USB Saves, select the encrypted save and use Copy save game → HDD. This import handles supported containers and applies the configured target identity; then inspect the imported save in HDD Saves. The locked USB menu differs from the decrypted-save menu and does not offer the same Apply Changes & Resign action. A save encrypted with keys unavailable on your firmware may fail before importing.

A different, unmodified PS4

First make the save work on the homebrew PS4 under the same real Account ID as the destination. Then use the PS4 Settings export to create a normal encrypted USB copy. On the destination, use Application Saved Data Management → Saved Data on USB Storage Device → Copy to System Storage under that same PSN account. A decrypted APOLLO folder is not a normal-console import.

Restore your own backup

For a normal encrypted backup, use the console’s USB saved-data import. For an Apollo decrypted backup, use USB Saves → the correct save → Copy save game → HDD under the matching user. Close the game first, check the title and slot, and confirm an overwrite only after preserving the save currently there.

Apollo decrypted working copy

USB drive/
└── PS4/
    └── APOLLO/
        └── <USER-ID>_<TITLE-ID>_<SAVE-NAME>/
            ├── sce_sys/
            │   └── param.sfo
            └── <game save files>

Apollo exports the working-copy folder name for you. Placeholder text in angle brackets is not a literal folder name. If your community download already has that structure, preserve it.

Without a physical USB drive, the documented /data/fakeusb/ source uses the same structures. Select that source in Apollo Settings. It is a folder on the PS4, not the normal PC USB drive.

Patches and other useful tools

Save patches / cheats
Only supported games show patch options. Back up, enable one suitable patch, use Apply Changes & Resign, then check the result in-game. A patch may depend on the exact save format or game version.
Export / import decrypted save files
These work with Apollo’s per-user export folders. They are advanced file-editing operations; use Copy save game for a complete beginner backup and restore.
Keystone backup
Keep the keystone from a working save for the exact game build. A keystone mismatch is separate from ownership. Follow the official keystone instructions only after making backups.
Settings and application data
Use the correct USB source, change sorting, update patch data, or enable the debug log when troubleshooting.

Apollo PS4 handles PS4 saves. For native PS5 saves, use the separate PS5 game-save tools page. PS3 saves also require their own workflow.

Troubleshooting

The save does not appear in USB Saves.

Extract the ZIP. Check PS4/APOLLO for decrypted data or PS4/SAVEDATA for an encrypted export, with no duplicate wrapper folder. Check Settings → USB Saves Source and refresh the list. Make sure the USB is readable and contains the full save.

The save belongs to another user.

Confirm which local user launched Apollo. Check its Account ID in About, then the save’s ID in View Save Details. For an offline user, complete the appropriate activation first, then resign a working copy and import it again.

Apollo shows a red warning or cannot decrypt the save.

Check the folder structure, container/.bin pair, and the encrypted save’s firmware key requirements. Resigning does not add encryption keys missing from your firmware. Keep the source backup and consult the exact Apollo build’s compatibility notes.

The game says the save is corrupt or will not load.

Check the exact title ID, game update, edition, required DLC and slot. For a confirmed keystone mismatch, follow the project’s keystone guide using a fresh working save from your exact installed build. Restore your backup if the modified copy still fails.

Can I change the CUSA number to fix a region mismatch?

Changing a folder label is not a universal conversion. Some games require moving compatible decrypted data into a fresh save from the destination build; others use different formats and cannot be transferred that way. Use game-specific instructions and retain both originals.

Will changing my PSN username convert or transfer this save?

No. The public Online ID and the save Account ID are different identifiers. Use save resigning for ownership and keep the destination game compatible.

Can this transfer server-side online progression?

This guide covers local save files. Progress stored on a publisher’s servers follows that service’s account system; changing local ownership does not transfer those server records.

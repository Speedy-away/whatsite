Wordle DS

  • v3.2.3
  • NDS

A native dual-screen word puzzle with daily words, statistics, mods and shareable results.

Hardware: DS / DS Lite flashcart · DSi / XL · 3DS DS mode

Setup & prerequisites
  1. Copy WordleDS.nds to /roms/nds/homebrew/ (a suggested library folder), then open it in your homebrew launcher.
  2. The game stores a completed result at /_nds/WordleDS/Wordle DS/share.txt; its statistics screen can show a QR result.

Use the NDS asset on flashcarts. The upstream .dsi asset carries a title ID for NTM; the CIA asset belongs to a separate 3DS install route. Neither is needed for the NDS download here.

A native Counter-Strike demake. Single-player remains usable; the original multiplayer server is closed.

  1. Extract the hardware ZIP. Put its .nds on your card and soundbank.bin plus counter_strike_music.raw at the storage root.

Prepare and launch DS homebrew

  1. Choose the right packageA DS / DS Lite uses the Flashcard TWiLight package with a compatible flashcart. A DSi SD-card setup uses the DSi package and its documented entry point.
  2. Keep the supplied folder layoutExtract the package and follow the matching installation page. For the Flashcard package, its _nds folder, roms folder and documented boot NDS file go at the flashcart microSD root.
  3. Use the correct app formatOpen the NDS or DSi build through the launcher specified by the project. GodMode9i’s cartridge functions have additional model-specific access requirements.
  4. Keep a backup before changesCopy your existing saves and SD files before replacing a setup. On DSi, follow the NAND-backup instructions before choosing whether to install Unlaunch.

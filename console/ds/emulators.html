nesDS

  • v2.1
  • NDS
  • DSi

NES / Famicom emulator with a dedicated DSi build and TWiLight Menu++ integration.

Hardware: DS / DS Lite flashcart · DSi / XL · 3DS DS mode

Setup & prerequisites
  1. For TWiLight integration, install its Virtual Console add-on, then copy nesDS.nds to /_nds/TWiLightMenu/emulators/.
  2. Keep your own NES/FDS games separately; back up the existing emulator before replacing it.

Use the flashcart-compatible .nds asset for flashcarts. The .dsi variant adds a DSi title identity for compatible DSi launch/install routes. The extension alone does not set the CPU mode. The CIA asset belongs to a separate 3DS installation format and is excluded here.

Famicom Disk System games additionally require your own disksys.rom BIOS at the SD root.

GameYob · mavica build

  • v0.5.3b-mavica
  • NDS

Game Boy / Game Boy Color emulator, including Super Game Boy enhancements and scaling options.

Hardware: DS / DS Lite flashcart · DSi / XL

Setup & prerequisites
  1. Place gameyob.nds in a folder such as /roms/nds/homebrew/. Choose gameyob_dsi.nds only for a launcher with DSi-mode support.
  2. Create /_nds/ at the storage root; this release saves its settings there. Select your own GB/GBC games in the emulator.

Use a launcher with working DLDI/storage access. The release notes acknowledge remaining Super Game Boy palette issues.

NitroGrafx

  • v0.9.1
  • ZIP → NDS

PC Engine / TurboGrafx-16 emulator with support for some CD-ROM², Super CD-ROM² and Arcade Card software.

Hardware: DS / DS Lite flashcart · DSi / XL · 3DS DS mode

Setup & prerequisites
  1. Extract NitroGrafx.nds and launch it through your homebrew menu. Create /NitroGrafx/ or /data/NitroGrafx/ for settings and saves.
  2. Keep your games in a folder of your choice. For CD titles, select your own System Card BIOS in Options → Machine → Select Bios and follow CDROM_readme.txt.

Some flashcarts need DLDI patching. No SuperGrafx emulation; game and CD compatibility varies. Published build is 0.9.1 even though the main-branch README says 0.9.2.

A7800DS

  • 5.2c
  • NDS

Atari 7800 ProSystem emulator with per-game configuration and high-score support.

Hardware: DS / DS Lite flashcart · DSi / XL · 3DS DS mode

Setup & prerequisites
  1. Copy A7800DS.nds to your card and launch with TWiLight Menu++ or Unlaunch on DSi, or a homebrew-capable flashcart.
  2. Optional game folders: /roms/a7800/ or /roms/a78/. An optional 4 KiB BIOS named 7800.rom goes in /roms/bios/, /data/bios/ or beside the emulator.

Use your own .a78/.bin games. The published build supports NTSC; PAL is unsupported. DS/DS Lite has less CPU headroom than DSi; do not assume identical performance.

StellaDS

  • 8.4a
  • NDS

Atari 2600 VCS emulator with touchscreen cartridge selection, per-game settings and ARM-assisted cartridge support.

Hardware: DS / DS Lite flashcart · DSi / XL · 3DS via TWiLight (DSi mode for ARM games)

Setup & prerequisites
  1. Copy StellaDS.nds to your flashcart microSD or console SD and launch it. Tap the cartridge slot to select your own .bin/.a26 game.
  2. Configuration and save data are created under /data/. Keep those files when updating.

Advanced DPC+/CDF cartridge types need DSi-class hardware running at 134 MHz for the intended experience. A flashcart normally runs in 67 MHz DS mode, including on a DSi/3DS. Older launchers may need DLDI patching.

Prepare and launch DS homebrew

  1. Choose the right packageA DS / DS Lite uses the Flashcard TWiLight package with a compatible flashcart. A DSi SD-card setup uses the DSi package and its documented entry point.
  2. Keep the supplied folder layoutExtract the package and follow the matching installation page. For the Flashcard package, its _nds folder, roms folder and documented boot NDS file go at the flashcart microSD root.
  3. Use the correct app formatOpen the NDS or DSi build through the launcher specified by the project. GodMode9i’s cartridge functions have additional model-specific access requirements.
  4. Keep a backup before changesCopy your existing saves and SD files before replacing a setup. On DSi, follow the NAND-backup instructions before choosing whether to install Unlaunch.

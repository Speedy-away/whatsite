Homebrew Menu · hbmenu

  • v0.11.0
  • ZIP → NDS

devkitPro’s file browser and launcher for native DS homebrew.

Hardware: DS / DS Lite flashcart · DSi via supported homebrew route

Setup & prerequisites
  1. Extract the release and use BOOT.NDS with the bootstrap appropriate to your flashcart or existing homebrew route.
  2. Place additional homebrew in /nds/ and keep required app data in the paths its publisher specifies. Read the release README before choosing a flashcart boot file.

This is a launcher for an already supported entry point, not a DSi exploit or a 3DS CIA installer. Bootstrap selection depends on the flashcart.

The original ready bundle also includes bootstrap.cia for a separate 3DS route. On DS/DSi use BOOT.NDS and the relevant flashcart bootstrap; do not install the CIA.

NitrousTracker · music studio

  • release/0.6.5
  • ZIP → NDS

A stylus-operated XM music tracker and sampler, with pattern editing and microphone recording.

Hardware: DS / DS Lite flashcart · DSi via compatible homebrew launcher

Setup & prerequisites
  1. Extract the ready ZIP. Copy nitroustracker.nds and the supplied songs/ and themes/ folders to your SD card. Launch nitroustracker.nds; debug and MIDI variants remain preserved in the original ZIP.
  2. Use the app’s file browser to load or save .xm songs and .wav samples in folders of your choice. Keep copies of your songs before upgrading the app.

This pins the ready 0.6.5 GitHub release. Later builds, including native 3DS and beta releases, have separate packages; they are not substituted for this DS build.

Samples must be uncompressed 8-bit or 16-bit WAV. Memory available for samples is smaller in DS mode than in DSi mode.

dsidl · DSi QR downloader

  • v0.1.1
  • DSi

A DSi-camera utility for downloading a file from a URL encoded in a QR code.

Hardware: DSi / DSi XL · DSi mode only

Setup & prerequisites
  1. Copy dsidl.dsi to the DSi SD card and open it with a DSi-mode homebrew launcher. A DS / DS Lite flashcart cannot provide its required camera and DSi Wi-Fi functions.
  2. Configure Wi-Fi through System Settings → Advanced Settings. Scan a QR containing a URL, then choose the SD destination folder and filename in dsidl.

The publisher labels v0.1.1 as a prerelease. Requires a working DSi camera, SD access and a compatible router. Its dsiwifi library has router limitations; the author says WEP/open networks may not work. Hold SELECT at launch for connection logs.

Prepare and launch DS homebrew

  1. Choose the right packageA DS / DS Lite uses the Flashcard TWiLight package with a compatible flashcart. A DSi SD-card setup uses the DSi package and its documented entry point.
  2. Keep the supplied folder layoutExtract the package and follow the matching installation page. For the Flashcard package, its _nds folder, roms folder and documented boot NDS file go at the flashcart microSD root.
  3. Use the correct app formatOpen the NDS or DSi build through the launcher specified by the project. GodMode9i’s cartridge functions have additional model-specific access requirements.
  4. Keep a backup before changesCopy your existing saves and SD files before replacing a setup. On DSi, follow the NAND-backup instructions before choosing whether to install Unlaunch.

Switch - Basic Light

  • v1.1.2
  • 7z → theme
  • DSi interface

A Nintendo Switch-inspired custom theme for TWiLight Menu++’s DSi interface.

Hardware: DS / DS Lite flashcart · DSi / XL · 3DS DS-mode launcher

Setup & prerequisites
  1. Extract the theme directory into /_nds/TWiLightMenu/dsimenu/themes/ on the storage used by TWiLight Menu++.
  2. Hold SELECT while starting TWiLight Menu++, choose the DSi interface in GUI Settings, select the custom theme and press B to apply.

Requires a working TWiLight Menu++ installation. “DSi” describes the menu interface, not an exclusive console model. Preserve any existing themes when copying.

Install a TWiLight skin

  1. Extract the themeOpen the ready 7z archive on your computer or phone. Copy its theme folder, rather than the unopened archive, to the storage used by TWiLight.
  2. Match the interface pathDSi-interface themes go under /_nds/TWiLightMenu/dsimenu/themes/. 3DS-interface themes go under /_nds/TWiLightMenu/3dsmenu/themes/. Each skin’s card names the correct one.
  3. Choose it in settingsHold SELECT when starting TWiLight Menu++, select the corresponding interface under GUI Settings, choose its custom theme and press B to apply. Keep other theme folders intact.

Install homebrew on your Switch

  1. Start with an existing homebrew setupUse the maintained Nintendo Homebrew guide for your exact Switch model. This catalogue assumes your console already runs a compatible CFW and can open hbmenu. An NRO is an app executable; copying one does not enable homebrew.
  2. Choose one installation routeFor on-console installation, open Homebrew App Store and find the app. For manual installation, use the pinned NRO or SD bundle here. Compare the version and read its requirements before replacing an older build.
  3. Keep the supplied foldersPut standalone NRO files at the path shown on the card. For a complete store ZIP, extract its SD-layout files onto the microSD root, keeping switch/, config/ and other runtime folders intact. Store info.json and manifest.install are package-manager metadata, not apps to launch.
  4. Open hbmenu with enough memoryFollow your CFW guide’s application-mode instructions. A common Atmosphère title-takeover setup opens hbmenu by holding R while starting an installed game and selecting a user. Album entry normally runs in restricted applet mode; use application mode when the project requires it.
  5. Launch, configure and keep backupsSelect the app in hbmenu, then follow its project documentation. Configure network hosts, FTP credentials or game data where required. Back up saves and existing configuration files before restoring data or updating a bundle.

Set up an emulator

  1. Choose the Switch build and its launch modeUse the Emulators category and check each card’s supported systems, release and memory requirements. Launch through full application mode when required. A legacy build with a documented current-system issue needs a compatible setup; its version is not a promise of support for every firmware.
  2. Keep the complete emulator packageAn emulator may need fonts, shaders, configuration or other runtime assets beside its NRO. Extract a complete SD bundle with its supplied folders intact. A standalone NRO is offered only when the project supports that route.
  3. Prepare its system and game filesFollow the emulator’s linked documentation for your own game dumps and any BIOS or firmware it requires. These are separate from the app download. Match the supported formats and paths; a PSP emulator and a Nintendo DS emulator have different requirements.
  4. Test controls, saves and performanceStart with one title and configure controls and audio. Keep in-game saves backed up separately. Save states can depend on the emulator version and are not a replacement for portable save backups.

Storage & file formats

Use the card’s documented path and keep enough free space for extracted files, downloads and save backups. Safely eject the microSD before removing it. The Switch setup guide recommends FAT32; follow its formatting instructions for your existing card.

File typeWhere it belongs
NRO appUsually sdmc:/switch/<app>/<app>.nro. The launcher itself is sdmc:/hbmenu.nro. Card-specific paths take priority.
Complete SD bundleExtract the ZIP and preserve its runtime folder layout. NXMP, ftpsrv and the bundled games here require their supplied resources or configuration.
CFW / bootloaderAtmosphère, Hekate, BIN payloads and system modules use their own documented setup and compatibility. Use the existing Switch CFW resources.
Source codeGitHub source ZIP/TAR archives need a build toolchain. Use a documented Switch release asset or store package for installation.
PC / mobile helperMoonlight’s Sunshine host and FTP clients run on your other device. Their Windows, Linux, macOS or Android builds do not go in /switch/.

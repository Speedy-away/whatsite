Install & use mGBA

  1. Install the Switch frontendCopy mgba.nro into sd:/switch/. Open it from hbmenu on a compatible Switch homebrew setup.
  2. Prepare your own gamesCopy your own supported Game Boy, Game Boy Color or Game Boy Advance dumps to a folder you can find in the emulator’s file browser. No game files are included.
  3. Choose BIOS settings if neededmGBA includes a built-in BIOS implementation. An external BIOS is optional for supported features; if you use one, configure your own matching dump in the emulator.
  4. Open a game and protect its savesBrowse to your game, check controls and make an in-game save. Back up save files before changing emulator versions; save states are not a substitute for portable game saves.

If something does not work

For a title that does not boot, check the dump format, BIOS choice and mGBA compatibility notes. This Switch build is separate from the project’s desktop and 3DS packages.

Two apps, one theme workflow

NXThemes Installer 3.0.2

The console installer applies themes, manages installed components and restores the stock menus. Use the existing archived Switch app entry for the verified NXThemesInstaller.nro.

The 3.0.2 release notes document firmware 23.0 / 23.0.1 support with Atmosphère 1.12.1 or newer. This installer support does not guarantee every community layout works on those versions.

Get NXThemes Installer Official 3.0.2 notes

Themezer-NX 3.3.1

Browse Themezer directly on your Switch. The current client offers Install & Save, Install Only and Download Only. Installing requires NXThemes Installer; browsing and downloading require an internet connection.

Place themezer-nx.nro in sd:/switch/Themezer-NX/ and launch it from hbmenu. This is the Switch NRO release, with no desktop installer required.

Install, reboot & restore

Start with working Switch homebrew. These themes require an original Nintendo Switch with Atmosphère. They do not provide a console exploit. Check the installer, Atmosphère and theme author’s requirements for your exact system version. Nintendo Homebrew setup guide

  1. Prepare the microSD cardPower off before removing the card. Keep a backup of your existing theme files and Atmosphère configuration. Put NXThemes Installer in its existing sd:/switch/Switch_themes_Installer/ folder. Themezer-NX is optional.
  2. Copy the theme componentsExtract a pack ZIP on your computer or phone. Copy the supplied .nxtheme files to a dedicated folder under sd:/themes/. For an individual download, copy that single .nxtheme unchanged. Do not unpack the internals of a .nxtheme file even when an archive app recognizes its ZIP-based format.
  3. Open the current installerBoot Atmosphère and open NXThemes Installer from hbmenu. Current 2.9+ installers extract HOME Menu resources on demand. The old repeated manual “Extract HOME Menu” step is no longer needed for 3.0.2; raw SZS export is for layout development. Do not share extracted Nintendo system files.
  4. Select the menus and installBrowse your pack folder, select the components you want, and install them. Match the shown menu targets; avoid installing multiple alternative layouts for the same menu. Cozy Snorlax requires Settings > Themes > Basic White. Read any compatibility or patch prompt before continuing.
  5. Reboot and check the resultReboot into the same Atmosphère setup to apply the changes. Inspect each changed menu. Firmware 20.0 changed applet icons and layout compatibility; automatic fixes cannot guarantee an old community layout still works. If a component is unsuitable, use Uninstall and choose an updated theme.
  6. Uninstall before a firmware updateUse NXThemes Installer’s Uninstall action to restore the menus, then reboot. Before reinstalling after an update, check that the new firmware is supported by Atmosphère, the installer, the theme patches and the author’s layout. Keep the downloaded original files as your backup.

Keep downloads separate from installed overrides

microSD root/
├── switch/
│   ├── Switch_themes_Installer/NXThemesInstaller.nro
│   └── Themezer-NX/themezer-nx.nro
└── themes/
    ├── Cozy Snorlax Adventures/
    │   └── [the pack’s .nxtheme menu components]
    └── The Great Wave off Kanagawa.nxtheme

The themes/ folder stores your downloadable originals. NXThemes Installer manages the active Atmosphère overrides separately. Leave your existing homebrew and unrelated game-mod folders intact.

The installer normally downloads compatibility patches automatically. For offline preparation, follow the official theme-patches project instructions for sd:/themes/systemPatches/, using patches that support your firmware. No copyrighted HOME Menu dump is provided here.

If a theme prevents HOME Menu from opening

  1. Preserve the affected overridePower the Switch fully off and access its microSD card from a computer. Back up and move sd:/atmosphere/contents/0100000000001000 off the card. This is the qlaunch / HOME Menu override directory; keep its bytes so you can inspect or restore them later.
  2. Boot without that theme overrideReinsert the card and boot Atmosphère. Once hbmenu is available, use NXThemes Installer’s Uninstall action to clean up remaining theme components, then reboot. Choose a layout documented for your current firmware before reinstalling.
  3. Check the official troubleshooting notesIf the problem persists, use the installer documentation and your CFW guide. Other applets or custom fonts have separate overrides; the installer’s normal Uninstall handles its theme targets. Do not remove unrelated atmosphere/contents directories.

Manage LayeredFS mod sets

SimpleModManager

Enable and disable compatible LayeredFS mod sets from an NRO app. Its storage layout is /mods/<game>/<mod>/contents/<title-id>/romfs/...; the part beneath a mod folder mirrors the Atmosphère folder tree. It does not turn incompatible game revisions into compatible ones, and Smash plugin/resource dependencies still need their own setup.

Download SimpleModManager Official setup & presets

Install one mod set at a time

  1. Check the game and update firstRead the game’s version from its software information and compare it with the selected mod. IPS files also require the matching build ID. Keep CTGP’s 3.0.3 requirement separate from the country patches for 3.0.5 and 4.0.0.
  2. Back up saves and existing modsUse a save manager before changing a gameplay mod. Copy the current mod folders somewhere safe. Move conflicting mod folders out of the active SD layout before enabling the new set.
  3. Follow the package’s actual folder layoutExtract complete console bundles and copy their documented directories to the microSD root. A Skyline plugin NRO belongs inside the game’s plugins folder; it is not an hbmenu app. Plain LayeredFS files, ARCropolis resources and IPS patches use different paths.
  4. Match framework and plugin versionsFor Smash, install only the dependencies required by the chosen mod. Skyline and ARCropolis are separate downloads. Keep one active Smashline runtime; its 2.0.0 API migration can affect earlier moveset plugins. Avoid replacing matched components from a complete pack piecemeal.
  5. Test the selected mod before combining itStart with one set and check its expected menu or title-screen indicator. Training Modpack is configured inside Training mode. Gameplay-changing multiplayer mods require the same versions and files on participating systems; follow the mod’s own network requirements.
  6. Disable or restore cleanlyUse the mod manager when supported, or move that mod’s own files out of the active paths and restore your previous backup. Do not remove shared Skyline or support plugins if other active mods still require them. Close the game fully between changes.

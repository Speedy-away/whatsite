Xbox instructions from help.txt

  1. Preserve original game filesConfirm the exact COD4 game build, title update and region/media ID first; the supplied help does not state them.
  2. Keep the supplied pairThe author places patch_mp.ff in the COD4 game directory and codjumper.xex on the console, then sets the XEX as a DashLaunch plugin. The archive does not state a required DashLaunch version.

CoDJumper and menu controls

  • Save position: double RS. Load position: LB. Previous saved positions: hold LB and press X.
  • UFO toggle: RB. Spawn static bot: D-pad Up.
  • Open menu: double X. Close: RS. Scroll: LT/RT. Select: X.

Forge and recorder controls

  • Open forge: in UFO mode, hold X and press RS.
  • Clone targeted object: in forge, hold X and press LS. Drop cloned object: hold X and press RT.
  • Start/stop recording: D-pad Down. Play recorded movement: D-pad Right.

Xenia documentation gap

help.txt also mentions a Xenia plugins directory and allow_plugins setting. The complete original archive has no plugins directory, so those instructions are retained as an incomplete alternative workflow rather than a complete PC-ready distribution.

Fortnite PS4 HWID unban file cleanup

This is a user-supplied file cleanup tip. Removing local download files has not been verified to lift an Epic Games account or hardware ban.

  1. Open the Fortnite title folderIn a PS4 file manager, go to /user/download/CUSAxxxxx/. Replace CUSAxxxxx with the title ID for your installed Fortnite region. Check the title ID before changing files.
  2. Back up and remove the two filesBack up the files first, then delete download0.dat and download0_infomation.dat if they are present in that Fortnite folder.

A new account is still required.

GoldHEN setup

  1. Check the installed title IDUse the active entry only for CUSA07669. The USA and Japan title ID, CUSA07022, is listed for reference with the plugin disabled.
  2. Copy the pluginClose Fortnite, then put fn.sprx in /data/GoldHEN/plugins/.
  3. Merge the INI and restartBack up /data/GoldHEN/plugins.ini. Copy the plugin path into your existing [CUSA07669] section, or add that section if it is missing. Enable plugin loading in the GoldHEN Plugins Menu and relaunch Fortnite.

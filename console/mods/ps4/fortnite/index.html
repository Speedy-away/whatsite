GoldHEN setup

  1. Check the installed title IDUse the active entry only for CUSA07669. The USA and Japan title ID, CUSA07022, is listed for reference with the plugin disabled.
  2. Copy the pluginClose Fortnite, then put fn.sprx in /data/GoldHEN/plugins/.
  3. Merge the INI and restartBack up /data/GoldHEN/plugins.ini. Copy the plugin path into your existing [CUSA07669] section, or add that section if it is missing. Enable plugin loading in the GoldHEN Plugins Menu and relaunch Fortnite.

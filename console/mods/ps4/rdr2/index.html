Havana

Havana by 0x199, ported to GoldHEN PRX by illusion, with a menu base by 2much4u ported to RDR2 by ethylamine. These files remain pinned to release tag v1.20, titled “1.2 GoldHEN PRX Port”.

Install the matching SPRX

  1. Check your game updateChoose rdr3Payload_129.sprx for RDR2 1.29 or rdr3Payload_132.sprx for 1.32. The author marks rdr3Payload_100.sprx for 1.00 as experimental.
  2. Enable Plugin LoaderThe release instructions require GoldHEN 2.3 or newer with Plugin Loader enabled. Back up your existing plugins.ini.
  3. Copy one matching pluginPlace the selected SPRX in /data/GoldHEN/plugins/. Preserve its filename.
  4. Merge the game entryAdd the selected plugin path under your installed game’s CUSA title ID in /data/GoldHEN/plugins.ini. The example below is for US title CUSA03041 and game update 1.32; change both the section and path to match your installation.
  5. Launch single-playerThe release says a loaded-menu notification appears during the loading screen. Load into single-player, then press R1 + Square.

US 1.32 example from the author

[CUSA03041]
/data/GoldHEN/plugins/rdr3Payload_132.sprx=true

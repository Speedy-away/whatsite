Dying Light 2: Stay Human · 01.00

This ready-to-use JSON contains cheat definitions for the GoldHEN in-game Cheat Menu. Preserve the filename; it is neither a PKG installer nor a standalone payload.

  1. Match the exact gameCheck CUSA12555 and installed game update 01.00 before selecting this file. Back up your save and any existing cheat file with the same name.
  2. Copy the JSON with your transfer toolUse FTP or a console file manager to copy CUSA12555_01.00.json to /user/data/GoldHEN/cheats/json/. GoldHEN supports only one cheat-file format per title ID and version at a time.
  3. Open GoldHEN Cheat MenuStart the matching game, then hold Share or use the quick double-PS trigger configured in GoldHEN. Highlight a cheat and press X to toggle it. Read the cheat’s own conditions before enabling it.

Pinned upstream revision: 3a4ca53414ed6653d091d9dcd82c838333585d2f. The source is the GPL-3.0 GoldHEN Cheat Repository. Firmware support depends on the GoldHEN release used by your console.

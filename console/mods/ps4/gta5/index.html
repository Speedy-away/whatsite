Post’s plugins.ini example

The later reply supplies the following configuration for its named Expulsion 1.57 plugin. Merge only the matching game entry into your existing configuration.

[CUSA00411]
/data/GoldHEN/plugins/LushModz-Expulsion-1.57.prx

Bundled INSTALL: GTA V CUSA00419 / 1.57

The package INSTALL specifies CUSA00419 and GTA V 1.57. Its own configuration differs from the forum reply’s CUSA00411 example above; use the section matching your installed title and the appropriate supplied build.

  1. Merge the supplied foldersUse FTP to merge the package’s data folder into PS4 /data and its user folder into PS4 /user.
  2. Enable the matching pluginThe package names /data/GoldHEN/plugins/LushModz-Expulsion-1.57.prx. Enable it under [CUSA00419] in your existing GoldHEN configuration, then fully close and restart GTA after replacing the PRX.
  3. Preserve saved mapsKeep /data/Expulsion/maps even when empty; map saving needs it. New saves use /data/Expulsion/maps/Expulsion_Map.txt. Do not overwrite an existing saved map during an update; none is included in this package.

Package’s plugins.ini example

; Enable only this GTA menu plugin.
[default]

[CUSA00419]
/data/GoldHEN/plugins/LushModz-Expulsion-1.57.prx
; /data/GoldHEN/plugins/ArabicGuy-Menu-Base-GoldHEN-main.prx

Included data and limits

  • /data/Expulsion/ugc/Expulsion_UGC.txt is a sample layout; /data/Expulsion/ugc/Expulsion_UGC_Actors.txt is a local actor preview. These are local layouts/previews, not saved Creator jobs or platform conversions.
  • Popup logos use /user/data/Expulsion/icons/youtube.png and /user/data/Expulsion/icons/x.png for ShellUI visibility.
  • The scripts folder is reserved for future script-loader support. Copying .osc/.csc files there does not currently inject them.
  • Legacy files directly under /data remain readable as fallbacks; new map saves use /data/Expulsion/maps.

GTA Reborn · GTA V 1.56

Game update and server availability

The ZIP contains separate 1.56/GTARBN.sprx and 1.57/GTARBN.sprx files. Choose the exact folder for your installed GTA V update. The supplied server announcement explicitly says “FOR 1.57 ONLY”; preserving the 1.56 client is not confirmation of current 1.56 server access. No PS5 or firmware compatibility is established.

Register and install

  1. Register yourself in GTA Reborn DiscordUse the server’s bot command /link username:YOUR_GAMERTAG. Replace YOUR_GAMERTAG with your PSN name exactly as it appears on your console, including letter case. The supplied instructions allow one registration per Discord account; each player registers from their own account.
  2. Save your personal registration fileThe bot replies privately with Reborn.txt. Copy that exact file to /data/Reborn.txt on your PS4. It is not included in this download and must come from your own registration. The supplied instructions say there is no in-game registration.
  3. Install the matching clientWith GTA V closed, copy the 1.56 client to /data/GoldHEN/plugins/GTARBN.sprx. The original ZIP contains both updates under different folders; the standalone download on this card is already the 1.56 file. Keep the other build separate rather than overwriting it by shared filename.
  4. Merge plugins.iniChoose your installed title ID in the region selector. Merge the generated section into /data/GoldHEN/plugins.ini and retain unrelated entries. Regional configurations are templates: embedded CUSA00419 request text does not establish a complete EU/USA compatibility matrix.
  5. Launch the server clientStart GTA Online with the correct Reborn plugin loaded and follow the server’s instructions. The supplied setup says a missing or incomplete /data/Reborn.txt prevents patches from being applied. Confirm that the client works before adding Ozark.

Registration command from the supplied instructions

/link username:YOUR_GAMERTAG

Required PS4 paths

/data/GoldHEN/plugins/GTARBN.sprx

Ozark setup

This Ozark setup requires the matching GTA Reborn client. Ozark 1.56 combined downloads include this exact 1.56 Reborn module and an INI with both plugin paths. Your personal Reborn.txt is still required; it is never generated or included by the website.

Other commands in the supplied guide

  • /playersonline [minutes] lists recently active players; the supplied default is 15 minutes. Example: /playersonline minutes:60.
  • /viewcrews lists available crews. /createcrew creates a crew with name and tag, plus optional motto, colour, owner, public/private setting and icon.
  • /linkcrew crew:TAG assigns a crew; the supplied instructions also accept its name or crew_id.

Troubleshooting from the supplied guide

  • Cannot join: check registration with /link and the presence of /data/Reborn.txt.
  • Patches were not applied: the supplied guide says Reborn.txt is absent or incomplete; retrieve your own file from the bot’s private reply.
  • Misspelled PSN name: contact the GTA Reborn server team to correct registration; do not register a friend from your account.

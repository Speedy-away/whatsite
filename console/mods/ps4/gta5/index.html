Scorpion v1.2b

Bundled installation guide

  1. Choose the matching game buildChoose the ScorpionMenu-v1.2b-1xx.prx file matching your installed GTA V update. The source example uses ScorpionMenu-v1.2b-146.prx for GTA V 1.46. The archive includes labelled 100 EU, 100 US, 138, 143, 146, 148, 149 and 150 variants.
  2. Transfer the plugin and data folderCopy the selected PRX to /data/GoldHEN/plugins and the Scorpion folder to /data.
  3. Merge the matching configurationEdit your existing /data/GoldHEN/plugins.ini. Use your installed CUSA section and replace the example’s 150 filename with the exact selected build.
  4. Start the gameLaunch GTA V after installing the matching files.

Source’s GTA V 1.50 example

[CUSA00419]
/data/GoldHEN/plugins/ScorpionMenu-v1.2b-150.prx=true

[CUSA00411]
/data/GoldHEN/plugins/ScorpionMenu-v1.2b-150.prx=true

Expulsion V5.0 · GTA V 1.57

Post’s plugins.ini example

The later reply supplies the following configuration for its named Expulsion 1.57 plugin. Merge only the matching game entry into your existing configuration.

[CUSA00411]
/data/GoldHEN/plugins/LushModz-Expulsion-1.57.prx

Bundled INSTALL: GTA V CUSA00419 / 1.57

The package INSTALL specifies CUSA00419 and GTA V 1.57. Its own configuration differs from the forum reply’s CUSA00411 example above; use the section matching your installed title and the appropriate supplied build.

  1. Merge the supplied foldersUse FTP to merge the package’s data folder into PS4 /data and its user folder into PS4 /user.
  2. Enable the matching pluginThe package names /data/GoldHEN/plugins/LushModz-Expulsion-1.57.prx. Enable it under [CUSA00419] in your existing GoldHEN configuration, then fully close and restart GTA after replacing the PRX.
  3. Preserve saved mapsKeep /data/Expulsion/maps even when empty; map saving needs it. New saves use /data/Expulsion/maps/Expulsion_Map.txt. Do not overwrite an existing saved map during an update; none is included in this package.

Package’s plugins.ini example

; Enable only this GTA menu plugin.
[default]

[CUSA00419]
/data/GoldHEN/plugins/LushModz-Expulsion-1.57.prx
; /data/GoldHEN/plugins/ArabicGuy-Menu-Base-GoldHEN-main.prx

Included data and limits

  • /data/Expulsion/ugc/Expulsion_UGC.txt is a sample layout; /data/Expulsion/ugc/Expulsion_UGC_Actors.txt is a local actor preview. These are local layouts/previews, not saved Creator jobs or platform conversions.
  • Popup logos use /user/data/Expulsion/icons/youtube.png and /user/data/Expulsion/icons/x.png for ShellUI visibility.
  • The scripts folder is reserved for future script-loader support. Copying .osc/.csc files there does not currently inject them.
  • Legacy files directly under /data remain readable as fallbacks; new map saves use /data/Expulsion/maps.

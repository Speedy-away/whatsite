Install GTA V Mods on PS4

Set up one matching plugin at a time, preserve your configuration and distinguish PRX plugins from CSC script resources.

Check the four compatibility details

You need a homebrew-enabled PS4 with GoldHEN plugin support, a supported GTA V update, the correct regional title ID and the menu’s required files. These instructions do not establish compatibility with the experimental PS4 14.00 HEN.

The supplied video is titled “PS4 - How To Install Velora Mod Menu For 1.57 (13.52 Or Lower)”. It is linked below. No transcript was available, so the written steps use GoldHEN documentation and the downloaded archive notes.

General GoldHEN plugin setup

  1. Confirm your installed GTA V updateUse Options > Information on the game tile. Choose either the 1.56 or 1.57 download group and check the menu’s supported title IDs.
  2. Back up configuration and savesCopy your existing /data/GoldHEN/plugins.ini before editing it. Keep unrelated game entries intact.
  3. Enable GoldHEN pluginsGoldHEN’s plugin documentation calls for version 2.3 or newer and enabling plugin loading in its Plugins Menu. Use a release supported by your firmware.
  4. Transfer the filesFor a matching PRX plugin, use FTP or your console file manager to place it in /data/GoldHEN/plugins/. Transfer any accompanying data folders to the location specified by that menu’s README. Do not rename a SPRX or CSC file to PRX to force it to load.
  5. Register the plugin for the gameAdd its exact file path under the matching GTA V CUSA section in /data/GoldHEN/plugins.ini. Use the menu’s regional configuration; avoid a default entry that loads it into every game.
  6. Test one menuFully close and restart GTA V, enter story mode and use the menu’s documented opening controls. If it crashes, remove that entry and restart the game before trying a different menu.

Expulsion 7.0: inspected archive layout

  1. Open the downloaded ZIP on your computerThe archive includes a PS4 folder, a PRX file and plugins.ini.example. Preserve its data folders when transferring them.
  2. Merge the PS4 data foldersCopy the archive’s PS4/data contents into the console’s /data. Its plugin is /data/GoldHEN/plugins/LushModz-Expulsion-1.57.prx. Review any additional user-folder instructions before copying them.
  3. Merge the example INIUse the supplied plugins.ini.example. It contains CUSA00411 and CUSA00419 sections pointing to the shared 1.57 plugin. Keep the section matching your installed game.
[CUSA00411]
/data/GoldHEN/plugins/LushModz-Expulsion-1.57.prx

[CUSA00419]
/data/GoldHEN/plugins/LushModz-Expulsion-1.57.prx

This example comes from the downloaded archive. It is for the named Expulsion 1.57 plugin, not a universal INI for every menu.

Oxagon / Oxagon Lite: GTA V 1.56

  1. Select the 156 pluginThe archives contain separate 153 and 156 PRX files. For this page’s 1.56 group, use Oxagon_156.prx or OxagonLite_156.prx.
  2. Transfer plugin and dataPlace the matching 1.53 or 1.56 PRX in /data/GoldHEN/plugins/ and the archive’s Oxagon folder under /data. The Lite README also requires /data/Oxagon.key, but the preserved Lite v1.4 ZIP does not contain that file. Obtain the required matching key from the source before treating the Lite installation as complete.
  3. Merge the correct game entryUse your installed GTA V title ID and the selected plugin’s exact path in plugins.ini. The archive’s region examples are examples; confirm your own game rather than inferring title ID from update number.
  4. Open the menuThe archive’s info.txt lists D-pad Left + Cross (X). Use one Oxagon build at a time.

Using CSC script resources

  1. Install a compatible loader firstThe supplied Script_Loader.zip is a resource pack, not a standalone PRX loader. Use a menu or script-loader plugin that documents support for your game update.
  2. Copy CSC/CTD files to its documented directoryUse the location required by that specific loader. Preserve accompanying CTD and text files; do not place CSC scripts in plugins.ini.
  3. Load one scriptSelect it through the loader’s interface. Read that script’s opening controls and stack-size notes before starting it. The supplied pack contains different requirements for different menus.

Back up and merge your existing configuration using the menu’s own example. Get Los Santos Online setup files and instructions from its website.

B33

Requirements

  • PS4 with GoldHEN enabled and plugin support.
  • Call of Duty: Black Ops 4, CUSA12446, updated to 1.26. The supplied README states that other versions cause the plugin to shut down.

Install B33 EXP

  1. Transfer the pluginUsing the GoldHEN FTP server on port 2121, copy b33_bo4.prx to /data/GoldHEN/plugins/b33_bo4.prx.
  2. Add its game entryIn /data/GoldHEN/plugins.ini, add the configuration below. If [CUSA12446] already exists, add the plugin path beneath that section.
  3. Launch Black Ops 4After a few seconds, the plugin displays: B33 EXP - L1 + R3 to open.

plugins.ini entry

[CUSA12446]
/data/GoldHEN/plugins/b33_bo4.prx

Usage

Wait a few seconds at the main menu before starting a game. The plugin loads the B33 script automatically; no external injector is required. In a LAN Multiplayer or Zombies match with bots, use L1 + R3 to open or close the menu. The menu switches between Multiplayer and Zombies modes automatically.

Status and co-host menu

  • LIVE in the top-right corner means the script is active.
  • NO GSC means the script failed to load; restart the game.
  • Players → player name → Co-Host Menu enables the other player’s menu. That player opens it with L2 + knife.

Uninstall

Remove the plugin line from plugins.ini, or delete b33_bo4.prx.

GSC Injector setup · no PC injector needed

  1. Enable GoldHEN plugin loadingUse a compatible GoldHEN release with plugin support and enable loading in the Plugins Menu. Back up your existing /data/GoldHEN/plugins.ini before editing it.
  2. Copy the injector pluginPut T7_GSC_Injector.prx in /data/GoldHEN/plugins/ using your console file manager or file-transfer method.
  3. Add the BO3 game entryUnder the CUSA section matching your installed Black Ops 3 title in /data/GoldHEN/plugins.ini, add the exact injector path shown below. Keep your existing game entries.
  4. Launch Black Ops 3 onceThe supplied injector setup notes say the first launch creates /data/T7 GSC Injector/. Close the game and confirm that the folder exists.
  5. Copy your GSC menu filesExtract the MuzzMan pack and copy its menu files into /data/T7 GSC Injector/, preserving any folders required by the pack. Copy extracted scripts rather than the ZIP archive.
  6. Relaunch and use the matching modeStart BO3 again and use the controls documented by your chosen menu or injector. Choose a script for Zombies or Multiplayer as appropriate and check its game-update requirements.

Later upload: documented build

The later SPRX archive README identifies DayBreak V1.1.2 for BO3 game update 1.33. It has separate CUSA02624 and CUSA02290 folders. These notes apply to that later upload; the original archive and the separate CUSA02624 reply ZIP remain available.

PS4 setup described in the later archive

  1. Choose the matching folderConfirm your installed BO3 title ID and update. Use the SPRX in the folder for your own title ID.
  2. Copy and register the pluginPlace DayBreak.sprx in /data/GoldHEN/plugins/ and add that exact path only under the matching CUSA section in /data/GoldHEN/plugins.ini. Preserve existing entries.
  3. Restart the gameRestart BO3. After “Press X to start”, the archive says to choose Yes at “Would you like to load DayBreak ZM SPRX?”.

Check the supplied configuration

The README examples hardcode CUSA02290 even inside the CUSA02624 folder. Use your installed game title ID. The included INI also lists unrelated plugins; merge only your own DayBreak entry.

PS5 notes supplied by the archive

For a matching NexHEN setup, the README says to place DayBreak.sprx in /data/nexHEN/plugins/. Add its exact path under your installed game title ID in NexHEN’s plugins.ini. Append ?autoload=true to the path for autoload, or leave it off and use NexHEN’s Plugin Loader. Start BO3 and accept the DayBreak loading prompt. Console compatibility has not been independently verified.

Loading and troubleshooting notes

For NexHEN autoload, the author says the load prompt may take up to 20 seconds at the main menu. If it does not appear, check the exact plugin path, your game title/update and duplicate INI entries. The README suggests trying DayBreak by itself when another BO3 plugin is loaded.

Installation

VirusMike BO3 AIO Pack V2

This is the original VirusMike V2 archive, with its injector, Multiplayer and Zombies scripts, INI example and readme. Extract it before use. The source lists BO3 game update 01.33 and CUSA03004, CUSA02290 or CUSA02624. These are source-stated requirements, not a physical-console test.

Prepare the supplied files

  1. Extract and match your gameKeep the original RAR. Extract its folders and check your installed BO3 title ID and game update. Use the matching GoldHEN environment supported by your console firmware.
  2. Place the selected injectorCopy this pack's T7_GSC_Injector.prx to /data/GoldHEN/plugins/. Preserve an existing injector with the same filename before changing it; the previously archived standalone build is different.
  3. Merge only the matching plugin entryIn /data/GoldHEN/plugins.ini, add /data/GoldHEN/plugins/T7_GSC_Injector.prx only under your installed BO3 CUSA section. Preserve existing entries. The pack's INI also names BO3-Customs and DeadOps plugins that are not included here, and repeats some sections; do not copy that entire INI over your configuration.
  4. Place the menu scriptsCopy the supplied T7 GSC Injector folder and its scripts to /data/T7 GSC Injector/. That directory is present as a literal path in this pack's PRX. Keep the MP and ZM filenames so you can select the intended mode.
  5. Select and inject from the lobbyEnable your configured GoldHEN plugin loading, then launch the matching game. The included readme says to select and inject a menu while in the game lobby before starting the match. It permits adding or removing menu files while the game is open.

The readme makes a broad firmware claim, but no specific firmware matrix or native PS5 instructions are supplied. Use the requirements of your compatible GoldHEN release. Preserve the source readme and all older archived builds.

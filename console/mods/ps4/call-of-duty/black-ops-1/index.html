Updated-fixes README

Made by xMasterModzx / Homiethefluff; ported to Black Ops Zombies by killhitman40. The README records release date 19 October 2026. On some maps, allow a few seconds before opening the menu. Some options are absent because they are not available in Black Ops Zombies.

Spawnables work only on the supported maps Nacht der Untoten and “Der Rise” (source spelling). Other maps can show no supported spawnables.

GSC Injector v1.0 — BO1 & BO2 (PS4/PS5)

Included Menus

  • BO2 MP — Jiggy • Project Abyss
  • BO2 ZM — ByGrEk • ByGrEk Nexus • Heidi v13 • EnCoReV9 • Project Iconic V3 • RMT
  • BO1 MP — Redemption • Encore v8 (+7 patches incl. NaTo V1 Treason Edit)
  • BO1 ZM — Encore V8 ZM

Injector filename

The attached PRX downloads as gsc2520injector.prx. The post’s installation steps and plugins.ini example use gsc%20injector.prx. Keep the installed filename and its plugins.ini path identical.

Install

  1. Put gsc%20injector.prx in /data/GoldHEN/plugins/
  2. Use the included plugins.ini (or add the injector lines to yours) → /data/GoldHEN/
  3. Copy the GSC Injector folder → /data/GSC Injector/
  4. Reboot, launch the game, load into a match

The complete example below also contains default and Playroom entries. Merge the relevant injector entries into your existing configuration.

Post’s plugins.ini example

; Note: lines starting with semicolon are for comments.
; Load plugins for any title.

[default]
/data/GoldHEN/plugins/game_patch.prx

; Load plugins only for Playroom.

[CUSA00001]
/data/GoldHEN/plugins/afr.prx
/data/GoldHEN/plugins/no_share_watermark.prx

[CUSA57548] ; This will load when toggled for this title ID.
/data/GoldHEN/plugins/gsc%20injector.prx

[CUSA57547] ; This will load when toggled for this title ID.
/data/GoldHEN/plugins/gsc%20injector.prx

Using the bundled item-ID reference

  • Enter decimal values in the tool’s numeric input; hexadecimal values are supplied only as a reference.
  • The bundled Miles v24 reference lists 116 dropdown entries. This catalog label does not establish the version of the supplied tool binary.
  • Categories identify the original table slots. An item’s name identifies its table ID, rather than verifying what happens when it is written to a different field.
  • The supplied catalog does not include attachments, camos or other cosmetic values.

Payload Injector + ps4debug.bin

Observed connection demonstration

The short video begins with address and port fields already filled. It does not show the initial payload receiver or firmware setup.

Fields shown in the source

BO2 PlayStation tool

Sequence visible in the clip

  1. Select the debug payloadIn PS4 Payload Injector, open the file picker and select ps4debug.bin.
  2. Injector state shownWith the payload path selected, the source displays Connected while the cursor is over Send Payload.
  3. Connect in the BO2 toolThe BO2 PlayStation tool uses the same console LAN address, port 744 and Local Client 0. Clicking Connect PS4 changes its display from Not connected to Attached • codmp.elf • pid 76 • RPC ready in the recorded session.

Local Client meaning

The source explains that Local Client 0 is the PS4 main player. Other values are local split-screen clients, not remote PS5 lobby slots.

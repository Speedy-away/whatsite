Check the firmware and Blu-ray requirements

This is a disc-based JAR Loader and UMTX workflow. It covers the listed 6.xx–7.xx builds between the browser guide bands. It requires a working Blu-ray drive; digital-only consoles need a different compatible entry point.

Supported versions in this guide: 6.00, 6.02, 6.50, 7.00, 7.01, 7.20, 7.40, 7.60, 7.61.

  • A PS5 with an enabled, working Blu-ray drive, on one of the exact versions below.
  • A computer, a Blu-ray writer and blank BD-R or BD-RE media. Use a recordable Blu-ray disc for this entry point.
  • The pinned v4.1.1 ISO and matching UMTX1 and process-jailbreak JARs.
  • A computer with Java 11 available, on the same local network as the PS5, to send the JARs.

Blu-ray preparation & JAR Loader steps

  1. Check your exact firmware and drive
    On PS5 open Settings > System > System Software > Console Information. Check the list below before preparing a disc. Keep the console on its existing firmware while checking compatibility.
  2. Get the matching JAR Loader filesJAR Loader ISO UMTX1 JAR Process-jailbreak JAR
    Use the v4.1.1 trimmed ISO for the disc, plus the matching updated UMTX1 and process-jailbreak JARs. The release notes specifically require sending the updated UMTX through the Remote Loader; the Full ISO contains an older UMTX copy.
  3. Burn the ISO to Blu-rayImgBurn 2.5.8.0
    In ImgBurn choose Write image file to disc, select ps5-jar-loader-4.1.1.iso, choose the Blu-ray writer and burn the image. Complete verification before removing the disc. The upstream instructions specify UDF 2.50 when creating a disc filesystem from source; the supplied ISO is already an image ready to burn.
  4. Open the JAR Loader on PS5
    Insert the disc, switch to Media and open Disc Player / PS5 JAR Loader. Wait for the remote loader to show that it is listening. Its default JAR port is 9025. Use the PS5's local IP address from its connection status.
  5. Send the updated UMTX1 JARUMTX1 JAR
    From the computer, use the upstream sender built into the matching JAR: java -jar umtx1-1.0-SNAPSHOT.jar <PS5_IP>. Replace <PS5_IP> with the console's local address. The sender uses port 9025 by default; append a port number only if your loader uses a different one. Wait for the console's completion messages before sending the next payload.
  6. Apply the BD-J process jailbreakProcess-jailbreak JAR
    After UMTX establishes kernel read/write, send java -jar jailbreak-1.0-SNAPSHOT.jar <PS5_IP>. This upstream payload gives the BD-J process root privileges and escapes its /app0 filesystem jail. Keep the loader and JAR payloads from the same release.
  7. Check the next payload separatelyPS5 payload resources
    This loader workflow establishes kernel read/write and a privileged BD-J process. Follow the specific ELF loader or homebrew-enabler project's supported firmware and entry-point instructions before proceeding. A successful JAR Loader run does not certify etaHEN or every app for all of these firmware versions.

What this method provides

Kernel read/write has firmware-specific limits. The upstream documentation warns that writing protected kernel-data regions on 6.00 and later can panic the console. Its kernel read/write capability is separate from support for a particular ELF loader, HEN or app.

The v4.1.1 release fixes 5.xx-and-later offsets and says to run its updated UMTX through the Remote Loader. Use those matching release files rather than assuming an older disc menu or another project's payload is interchangeable.

On the listed 7.xx versions, the Relapse browser page is also available. For 6.xx, this page documents the Blu-ray path. Y2JB has different app and installation prerequisites.

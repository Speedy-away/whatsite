Prospero Explorer

1.0 · ZIP app bundle

Browse console files, manage archives and packages, and use the project’s network tools.

PS5 native folder module, PPSA99109. Publisher installation uses dump_installer and a home-screen launch; its pinned README/release does not supply a firmware test matrix.

Installation & requirements

This ZIP has eboot.bin, sce_module and sce_sys at its root. Extract all four files into a folder such as PPSA99109, place that folder under /homebrew on the selected USB drive or /data/homebrew on the console, install with dump_installer, then launch its home-screen tile.

  • An active PS5 homebrew environment compatible with the publisher's native module
  • dump_installer for registration, as specified in the v1.0 release
  • Keep sce_module/libc.prx and sce_sys beside eboot.bin

The Network page exposes the app's file service with its own login, read-only and root settings. Use the address displayed by that service; no ezRemote endpoint compatibility is claimed.

Prospero Multi Tools

1 · ZIP app bundle

Manage supported homebrew and backup layouts. The project requires its unjail payload.

PS5 native module PPSA99110; requires SvenGDK's unjail daemon on a firmware it supports. The daemon must be running before the app starts and must be sent again after a reboot. PS1/PS2/PSP launch functions additionally require the separate emulator resources.

Installation & requirements

Extract the included PPSA99110 folder and copy it intact to USB /homebrew/PPSA99110 or internal /data/homebrew/PPSA99110. Register with dump_installer, send the author's unjail payload before opening, and use Diagnostics to check actual reachable storage. EmulatorPack.zip is a separate dependency for emulator launch features.

  • Firmware covered by the author's unjail-ps5app-payload support table
  • unjail daemon active whenever the module needs storage or install access outside its sandbox
  • dump_installer
  • Separate emulator folders and emulator-resources for PS1/PS2/PSP launch features

Diagnostics checks the escalation daemon, file broker and actual reachable roots; PS5 Tools also offers its documented payload sender and service-port probes. Backup inspection for other consoles is not a claim that those console games run natively on PS5.

Chiral-FTP

1.1 · ZIP app bundle

Manage console files and connect through the project’s FTP, SFTP and web tools.

PS5 native title PPSA96024. Requires ShadowMountPlus and elfldr listening on port 9021 at app startup for full storage access. The author reports testing on firmware 13.60; other firmware is untested in the pinned README.

Installation & requirements

Copy the complete PPSA96024 folder to /data/homebrew/PPSA96024 and preserve 0777 on the folder and every file. Launch from the dashboard with elfldr active. Its start screen reports whether full storage access succeeded; closing the app stops its servers.

  • ShadowMountPlus
  • ELF loader on port 9021 when the app starts
  • 0777 app-folder/file permissions, as documented by the author

Open the running app's Web app or FTP server screen and use its displayed endpoint and login. These are Chiral's services; the site's ezRemote JSON commands must not be sent to them. Quick connect uses a code shown on both devices and explicit Allow.

  • Compatible active PS5 homebrew app environment
  • Supported external USB audio-CD drive; internal console drive is not used
  • Local ELF loader on port 9021 may be required for the bundled title-specific helper

ProsperoWeb

Browse websites with controller navigation, tabs and bookmarks in a native PS5 app.

Experimental PS5 native browser PRWB00001. Requires a jailbroken PS5 with etaHEN or kstuff, ShadowMountPlus, and privileged elfldr at 127.0.0.1:9021; websrv on 8080 is a fallback.   • Jailbroken PS5 with etaHEN or kstuff
  • ShadowMountPlus
  • Privileged ELF loader listening on 127.0.0.1:9021 for child processes; websrv 8080 fallback
  • Manual transfer/extraction for this large app bundle

ProsperoLight

01.000.110 · ZIP app bundle

Native PS5 Moonlight-style client for streaming games or a desktop from a Sunshine-compatible PC. Pair your own host; PC games are streamed, not installed on the PS5.

Native PS5 app, PPSA99002. Requires an already compatible homebrew environment and title loader plus a reachable Sunshine-compatible host. The pinned README gives no universal firmware matrix.

Installation & requirements

Close the app before updating. Extract the complete PPSA99002/ folder into /data/homebrew/, keep one installation of this title and refresh title registration in your compatible loader. Start Sunshine on your PC, select or add its address in ProsperoLight and enter the pairing PIN on the host. A wired LAN is recommended. Touchpad + L1 ends a stream. Pairings/settings normally stay in /data/prosperolight.

RecompStore

PS5 homebrew store for native recompiled ports, emulators and apps. Game setup uses your own disc images or other required source files; no commercial game data is in this download.

Native PS5 app, PPSA92000. Publisher requires kstuff, an ELF loader on TCP 9021 and ShadowMountPlus 1.7 Beta 5 or newer. No firmware range is inferred from these prerequisites.

Installation & requirements

Manual install: extract the complete PPSA92000/ directory into /data/homebrew/ and let ShadowMountPlus register the title. Alternatively use the separately archived matching RecompStore-Installer.elf. The installer fetches the newest upstream build when online, or uses its embedded copy offline; use this pinned ZIP for an exact v2.7.4 install. Keep required data, modules and included payloads together. Follow each port’s own game-input requirements.

Playden requirements

Playden’s project tests on firmware 13.60 and requires kstuff, ShadowMountPlus and an ELF loader. Installation also needs a supported transfer service. It uses a separate runtime kit and does not promise compatibility with every Windows game.

Back up Steam Cloud saves before testing: Playden can upload saves. Games with anti-cheat and online multiplayer are not supported by the documented setup.

Back up and import saves with Garlic SaveMgr

Garlic SaveMgr · v1.14

Browse, export and import saves on a homebrew-enabled PS5 through a browser on your local network.

Download Garlic SaveMgr ELF Release notes Project instructions
  1. Open the save manager. Send the ELF to elfldr on your homebrew-enabled PS5. On a computer or phone on the same network, open http://<PS5 IP>:8082.
  2. Export your current save. Close the game, choose the correct user in Garlic SaveMgr and keep a separate backup before importing anything.
  3. Check the save before importing. Match the platform, title ID and save slot. Use Garlic SaveMgr’s import option for a complete save in a supported format, then launch the matching edition and confirm the expected progress.

PlayStation backup options

PlayStation Plus can sync individual saves. The built-in USB backup can include PS5 saved data as part of a console backup; restoring it erases the data currently on the console.

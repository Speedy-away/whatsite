Open the host in the PS5 browser

Open your PS5 host on the console, select your exact firmware from the listed 1.00–5.50 versions, then choose UMTX2:

https://speedy-away.github.io/hosts/ps5/

Use your existing compatible browser entry or User’s Guide redirect. A browser shortcut package requires package-installation access first. The UMTX2 project also includes a self-host option; its inherited setup redirects manuals.playstation.net to the computer hosting the page, with that computer’s LAN address as DNS.

  • UMTX2 hosts and browser entry options
  • Project’s self-hosted User’s Guide setup

There is no fixed public DNS address supplied by this UMTX2 guide. A User’s Guide DNS redirect alone does not establish Sony server blocking. An update-blocking host may also restrict PSN services; follow that host’s own instructions.

For normal online play, restore DNS Settings → Automatic or your usual DNS. This can allow update connections again. Using a jailbroken console on PSN risks a console ban, account ban, or both; changing DNS does not make it safe.

Run UMTX2 · step by step

  1. Check the host’s firmware displayThe page checks the console firmware against its allowlist. Stop if it reports an unsupported version.
  2. Choose JailbreakUse the normal Jailbreak button for initial kernel access. The Webkit-only (sender) option expects a loader that is already running; it does not start the kernel chain.
  3. Follow the on-screen progressThe host can reload and retry after an error. Wait for its payload screen and listening address before sending anything. An error or console restart does not confirm success.
  4. Check the loader resultThe build attempts to start John Tornblom’s ELF loader on TCP port 9021 and also exposes its older port 9020 loader. Read the displayed IP address, ports and any loader errors.
  5. Choose one compatible payloadUse the payload menu or your matching sender. Check that the payload supports your exact firmware and the loader being used, then confirm its result before adding another.
  • Loader ports, sender mode and completion screen
  • Run button and retry behavior

After the loader is working

A successful browser exploit does not establish compatibility for every PS5 app or payload. Use each project’s firmware requirements when choosing homebrew. Y2JB installation is a later setup step that needs its own supported firmware and working homebrew access.

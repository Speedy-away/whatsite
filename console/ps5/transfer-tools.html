Save files on the PS5

Console Downloads uses /data/whatwhatboy for internal storage, or a whatwhatboy folder on an actual detected USB/external mount. Choose Prepare download folder, then explicitly create or verify it through the running ezRemote Client on port 9090. Return to the downloader on background-server port 6701 before saving a file.

PS5 websrv on port 8080 supplies destination checks, mounted-storage detection and a read-only filesystem browser. Folder creation and reviewed-archive extraction use the separate client page on port 9090. Each extraction needs its own action and a new output folder; opening a page never extracts or runs a file.

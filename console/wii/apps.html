WiiMC

Media player

1.3.4ZIP · native Wii DOL

Browse and play supported local media with WiiMC’s Wii interface.

Wii · Wii U vWii · Wii Mini

Launch file/apps/wiimc/boot.dol

Download ZIP · 5.98 MiB OSC package & compatibility
Setup, requirements & checksum

Storage setup. Copy the complete apps/wiimc directory and browse your SD/USB media from inside WiiMC. Keep settings and supplied XML files together. OSC’s package includes its documented online-media configuration treatment.

Prerequisites. Working Homebrew Channel; IOS58 is needed for WiiMC USB 2.0 support. Follow the model-specific guide if IOS setup is needed. DVD playback depends on drive support; newer Wii drives and vWii cannot read DVD video.

OSC specifies no System Menu version for this app; a working Homebrew Channel for your console model is required.

Controllers: Wii Remote, Classic Controller. GameCube controllers require suitable hardware; standard vWii has no native GameCube ports.

File manager

Manage SD/USB files through a Wii file browser with keyboard and network features.

Wii · Wii U vWii · Wii Mini

Launch file/apps/wiixplorer/boot.dol

Download ZIP · 2.34 MiB OSC package & compatibility
Setup, requirements & checksum

Storage setup. Copy apps/wiixplorer and launch it in Homebrew Channel. Select the SD or USB device in its file browser. Back up files before moving or replacing them; its NAND-writing features require particular care.

Prerequisites. Working Homebrew Channel. Preserve supplied meta.xml/AHB access flags. Network features require configured networking, which a stock Wii Mini lacks.

OSC specifies no System Menu version for this app; a working Homebrew Channel for your console model is required.

Controllers: Wii Remote, Nunchuk, Classic Controller, GameCube Controller, USB Keyboard. GameCube controllers require suitable hardware; standard vWii has no native GameCube ports.

Add an app to the Homebrew Channel

  1. Extract the console buildFor an app ZIP with an apps folder, copy that folder to the root of the storage device used by your Wii setup. Keep each app in its own subfolder.
  2. Keep the executable and app information togetherA normal Homebrew Channel app folder contains boot.dol or boot.elf, with meta.xml and icon.png when supplied.
  3. Set up Nintendont’s three filesRename the downloaded loader.dol to boot.dol and place it with its linked meta.xml and icon.png in /apps/Nintendont/. This page pins the upstream build snapshot rather than assigning it a new release number.
  4. Launch the app and finish its own setupOpen the Homebrew Channel, select the app and follow its project instructions. Loaders, storage devices and disc tools can have additional requirements.

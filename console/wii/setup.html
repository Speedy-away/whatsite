Nintendo Wii · Homebrew setup & storage

Follow the route for Wii, Wii Mini or Wii U vWii and prepare the storage and Homebrew Channel app folders it requires.

Start with your Wii model

Wii, Wii mini and Wii U’s vWii have different setup routes. Use the maintained guide’s console selector. Homebrew Channel launches apps; cIOS adds features used by loaders. Install the files and settings documented for your model.

  1. Identify the consoleCheck whether you have a Wii / Family Edition, Wii mini or Wii mode on Wii U. An already modified system should use the guide’s existing-homebrew route.
  2. Prepare storage and homebrew accessFollow the selected exploit to install the Homebrew Channel. The Wii guide lists what SD or USB storage each model can use.
  3. Make the documented backupCreate and keep the console backup specified by the guide, then complete its Priiloader and model-specific cIOS sections before using loaders.

Choose storage for your model

Wii · RVL-001 / RVL-101

Use the Wii route in the maintained guide and a working Homebrew Channel. These app packages use FAT32 SD or compatible USB storage. GameCube ports exist only on RVL-001.

SD:/apps/app/boot.dolUSB:/apps/app/boot.dol

Wii Mini · RVL-201

Use the Mini-specific setup route. A stock Mini has no SD slot or Wi-Fi: use a compatible FAT32 USB drive. Network features and GameCube-port features are separate hardware limitations, even when an app supports Mini.

USB:/apps/app/boot.dol

Wii U · vWii

Install homebrew through the vWii route, then launch these Wii builds from the vWii Homebrew Channel. Use FAT32 SD or a compatible FAT32 USB device; Wii U-formatted storage is different. Ordinary vWii homebrew does not automatically support the Wii U GamePad.

SD:/apps/app/boot.dolSD:/apps/scummvm/boot.elf

Firmware and system software: these twelve OSC manifests list supported models, not a universal System Menu version. Start with homebrew access for your exact console. Do not update, downgrade, install another model’s IOS or replace a regional System Menu just to add an app. WiiMC has an IOS58 requirement for USB 2.0; cIOS setup remains a separate requirement for the existing Wii backup loader.

Copy the extracted apps directory to the device root, alongside any other root data folders supplied by the ZIP. Keep meta.xml and icon.png beside boot.dol or boot.elf. Back up your existing saves and settings before copying an update.

Add an app to the Homebrew Channel

  1. Extract the console buildFor an app ZIP with an apps folder, copy that folder to the root of the storage device used by your Wii setup. Keep each app in its own subfolder.
  2. Keep the executable and app information togetherA normal Homebrew Channel app folder contains boot.dol or boot.elf, with meta.xml and icon.png when supplied.
  3. Set up Nintendont’s three filesRename the downloaded loader.dol to boot.dol and place it with its linked meta.xml and icon.png in /apps/Nintendont/. This page pins the upstream build snapshot rather than assigning it a new release number.
  4. Launch the app and finish its own setupOpen the Homebrew Channel, select the app and follow its project instructions. Loaders, storage devices and disc tools can have additional requirements.

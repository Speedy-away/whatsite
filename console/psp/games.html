CrossCraft Classic

Independent implementation of Minecraft Classic creative building.

Requires: Homebrew-enabled PSP; project is archived (May 2024). Official project describes Classic v0.30 creative mode, saves and multiplayer; not a Minecraft Java/Bedrock binary.

Installation & storage path

Create PSP/GAME/CrossCraft/ and extract all six files from the PSP ZIP into it: EBOOT.PBP, CrossCraft-Classic.prx, default.zip, config.cfg, LICENSE and README.md. Preserve default.zip as the bundled data archive. Multiplayer needs a WLAN-equipped model.

App path: PSP/GAME/CrossCraft/EBOOT.PBP

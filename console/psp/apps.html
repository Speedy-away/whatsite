Apollo Save Tool

Manage PSP and PS1 saves, export/import and apply source-provided save patches.

Requires: Homebrew-enabled PSP. Save decryption requires game-specific keys; author documents SGKeyDumper / SGDeemer. Back up original saves before editing.

Installation & storage path

Extract APOLLO into PSP/GAME. Author scans Memory Stick saves in ms0:/PSP/SAVEDATA/ and PSP Go internal memory. Launch from Game.

App path: PSP/GAME/APOLLO/EBOOT.PBP

CMFileManager PSP

File management, text editing, image/audio playback, archive extraction and FTP.

Requires: Custom firmware. Standard build covers regular PSP and PSP Go without external M2. Use GO-M2 build if the PSP Go has an external memory card.

Merge the archive’s PSP folder into the storage root, producing PSP/GAME/CMFileManager/EBOOT.PBP. Keep every file together. Select the GO-M2 ZIP for PSP Go with external M2; standard ZIP for other setups. FTP: START → FTP connection, anonymous login, port 1337. Street has no WLAN.

PKGi PSP

On-device downloader with a homebrew database and ZIP installation support.

Requires: Custom firmware and a WLAN-equipped PSP for downloads. This homebrew-db package contains a homebrew catalogue. Content requiring a license also requires your own valid console activation and license.

Installation & storage path

Copy the full PKGI folder to PSP/GAME/. The homebrew-db asset includes the homebrew list. Config and pkgi.txt live with the app. PSP Go defaults to internal ef0 storage; set storage ms0 in its config to choose Memory Stick. Network use requires WLAN.

App path: PSP/GAME/PKGI/EBOOT.PBP

PicoDrive

Sega emulator; this asset is the native PSP build.

Requires: Homebrew-enabled PSP. Supply your own ROMs. Sega/Mega CD requires a suitable user-supplied BIOS. Feature availability and speed depend on PSP build and game.

Installation & storage path

Extract and retain the complete PSP package under PSP/GAME/PicoDrive. Consult included README for supported ROM and BIOS names.

ScummVM

Adventure game interpreter with a current native PSP package.

Requires: Homebrew-enabled PSP and supported game data you own or official freeware data. All plugins must match exact ScummVM version. 81 MiB official PSP package; updated 18 October 2026.

Installation & storage path

Copy the full scummvm folder to PSP/GAME/. Keep its exact-version plugin folder and kbd.zip with EBOOT.PBP. Add supported game data through the launcher. Source paths: ms0:/scummvm_savegames/ and ms0:/scummvm.ini; check ARK Go redirection before assuming an ef0 path.

App path: PSP/GAME/scummvm/EBOOT.PBP

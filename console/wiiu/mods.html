Match the game before copying files

Use your own game, update and DLC files. A mod must name the supported platform, game revision, region and language. Keep a clean save backup and test offline first. Install and undo an SD mod

  1. Confirm the release requirementsCheck the original mod instructions, including game version, region and any required DLC. Do not use Switch mods or Cemu graphics settings as native Wii U files.
  2. Use the full-game title IDFor SDCafiine, use the full-game ID, not its update ID. The project documents EUR Super Smash Bros. for Wii U as 0005000010145000; this is an example for that exact game/region only.
  3. Preserve the complete mod packCopy its content tree to SD:/wiiu/sdcafiine///content/. DLC redirection uses aoc/ when the mod documents it. Keep filenames and letter case intact.
  4. Select one mod packEnable SDCafiine in its Aroma settings and relaunch the game. Use the mod’s own loader if its guide calls for a different environment; Second Wind is one such case.
  5. Undo without replacing game filesDisable SDCafiine and restart the game, or move the chosen mod folder off SD while powered off. Keep Preparing modpack visible if using auto-apply: X on that screen bypasses the automatic pack. Retain your original archive and saves.
SD:/wiiu/sdcafiine/[FULL_GAME_TITLE_ID]/[MODPACK]/
├── content/  → base game files
└── aoc/      → DLC files when documented

Online play and mod compatibility

Follow the game community’s online rules and the mod author’s multiplayer compatibility notes. Disable gameplay-changing mods before using ordinary matchmaking unless that exact mod and lobby support them. Pretendo is a network replacement, not a mod compatibility layer.

Riivolution Patcher

Release
v1.06
Requires
vWii Homebrew Channel and the original supported retail disc. Riivolution patch XML must match the disc game/region. Optional channel installation writes NAND; it is not required to launch the app from HBC.
Format
ELF · complete ZIP

Extract the complete apps/riivolution folder to SD root. Keep each mod’s XML in /riivolution/ and its data at the paths named inside that XML. Launch from HBC with your retail disc inserted. Disable patches to return to the original game.

Set up the separate Wii environment, choose source-confirmed vWii apps and games, and find Wii online services and GameCube support.

Wii U mode and vWii use different apps

Use the maintained vWii-specific guide. Wii U WUHB apps go under /wiiu/apps/; vWii Homebrew Channel apps use /apps//boot.dol at the SD root. The same card can hold both trees. Keep a NAND backup. BootMii cannot be installed on vWii; do not substitute ordinary Wii system files, IOS packages or themes.

Install and maintain the Wii environment

  1. Start from the maintained guideWith Aroma and the required backups prepared, use the guide’s Compat Title Installer Aroma build. It installs the vWii Homebrew Channel; it is not a native Wii U game launcher.
  2. Prepare controls and storageUse a compatible Wii Remote and the peripherals required by each app. Back up the SD card before changes. Keep the entire app folder, including meta.xml, icon.png and runtime data.
  3. Follow vWii-specific system stepsUse the guide’s model-specific Priiloader and cIOS instructions when the task needs them. An emulator or Homebrew Channel app does not automatically require cIOS. Avoid old Wii-only installers.
  4. Keep evWii on the Wii U sideThe archived evWii WPS controls vWii display/power behavior from Aroma. Its documented limitations still apply; it is not installed inside the vWii Homebrew Channel.

Ready apps with source-confirmed vWii support

WiiMC · 1.3.4

Browse and play supported local media with WiiMC’s Wii interface. Working Homebrew Channel; IOS58 is needed for WiiMC USB 2.0 support. Follow the model-specific guide if IOS setup is needed. DVD playback depends on drive support; newer Wii drives and vWii cannot read DVD video.

CSE2’s Wii port of the original freeware Cave Story, maintained by autumn_mnya. Working Homebrew Channel, an SD card and the complete supplied freeware-data package. Wii Remote and Classic Controller are listed by OSC.

SuperTux Wii · 0.1.4-wii-d.07

A native Wii port of SuperTux Milestone 1, updated by DeltaResero. Working Homebrew Channel and the complete supplied game-data folder. Wii Remote controls are supported.

Snes9x GX · 5.0.4

A native Wii SNES emulator with controller profiles and save support. Working Homebrew Channel and your own SNES ROM files. Game compatibility varies.

Not64 · 2026-04-10

Extrems’ Nintendo 64 emulator for Wii, with per-game compatibility and performance limits. Working Homebrew Channel and your own N64 ROMs. A Classic Controller or Nunchuk is useful for the N64 controls.

WiiSXRX · 3.3 Beta

PlayStation emulation using the smaller FS build. This pinned 3.3 Beta package does not support CDDA audio. Working Homebrew Channel and your own supported disc image. HLE is available; a real BIOS is optional. Return to the emulator menu to save before exiting.

Helium Boy · 0.1.1

Bertil’s original balloon-powered platform game for Wii. Working Homebrew Channel, an SD card and a Wii Remote with Nunchuk, with all supplied data retained.

WiiXplorer · r259

Manage SD/USB files through a Wii file browser with keyboard and network features. Working Homebrew Channel. Preserve supplied meta.xml/AHB access flags. Network features require configured networking, which a stock Wii Mini lacks.

Download complete ZIPSetup & checksum

Visual Boy Advance GX · 3.0.4

Run Game Boy, Game Boy Color and Game Boy Advance software on Wii. Working Homebrew Channel and your own GB/GBC/GBA ROM files.

The native Wii port of mGBA, with its own file browser and emulator interface. Working Homebrew Channel and your own supported ROM files. This is the Wii DOL port, not the separate Wii U build.

ScummVM · 2026.1.0

Run supported adventure-game data through ScummVM’s native Wii port. The archived OSC package is pinned to 2026.1.0. Working Homebrew Channel and the game-specific data files listed by ScummVM. Games are separate from this engine. Check the project for newer upstream versions.

Download complete ZIPSetup & checksum

FCE Ultra GX · 4.0.3

Play NES and Famicom software with saves, cheats and controller mapping. Working Homebrew Channel and your own NES/Famicom ROM files.

Download complete ZIPSetup & checksum

GameCube games through Nintendont

The official Nintendont project supports Wii U in vWii mode. Use your own GameCube dumps from SD/USB and a supported controller. Its Wii-only disc and physical memory-card features do not apply to vWii. Follow the upstream layout and controller documentation before choosing a forwarder.

Confirm CFW eligibility first

CFW is not supported on every PS3. Check the exact model and the PS3 Toolset compatibility report. Do not install a CFW PUP on an incompatible console; use the supported HEN route instead.

Flash operations can leave a console unable to boot. Keep an untouched flash backup and stop if a check fails. The exact procedure depends on model, flash type and whether CFW is already installed.

CFW installation workflow

  1. Identify the starting stateRecord the console model and firmware. If it already runs CFW, use Evilnat’s update instructions rather than repeating a retail-console flash-patching procedure.
  2. Read the Toolset reportOpen the official Toolset in the PS3 browser and let the system inspection finish. Continue only when your specific console is reported CFW-compatible.
  3. Back up flash memoryUse the tool’s backup function and copy the untouched dump to your computer and a second storage location. Preserve it before any patch is applied.
  4. Validate the dumpUse the matching PyPS3tools checker and review its report alongside the Toolset results. Resolve every failure before proceeding; a backup with errors is not a reliable recovery copy.
  5. Follow the supported patch procedureFor a compatible retail system, follow the Toolset’s documented flash-patching sequence exactly. Keep power stable and wait for explicit completion. Do not improvise offsets, flash files or recovery actions.
  6. Prepare the correct Evilnat PUPDownload the matching 4.93 build from the developer’s release page and verify its published checksum. Put the validated file on FAT32 USB storage as PS3/UPDATE/PS3UPDAT.PUP.
  7. Install and verifyFollow the developer’s reboot/update sequence, using Update via Storage Media or the stated recovery method. After completion, check the installed CFW version and confirm Package Manager and homebrew work.

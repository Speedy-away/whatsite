Install from USB

Sony documents this ordinary Theme Settings route. Use it when the PS3 browser cannot download a theme.

  1. Save the ready P3TChoose Download .p3t above. On a computer, save the file to Downloads. On a phone, save it in Files or Downloads, then move it to a USB drive using a compatible adaptor or transfer it to a computer first. Keep the .p3t extension; do not rename it to .pkg or .zip.
  2. Prepare the foldersUse a FAT32 USB storage device your PS3 can read; Sony also lists FAT16 support. Create a folder called PS3 at its root, then a folder called THEME inside it. Copy the .p3t file into THEME. The themes here are already P3T files and need no extraction.
  3. Install on the PS3Connect the storage device, then open Settings > Theme Settings > Theme > Install. Choose the storage device and theme. Installation copies the theme to the system storage.
  4. Apply your themeReturn to Settings > Theme Settings > Theme, select the installed theme and choose Apply. You can now disconnect the removable storage.

Download in the PS3 browser

  1. Find a theme on your phone or PCOpen Download on a PS3 on its card and note the short address. Each one is supplied by Themezer for that exact theme.
  2. Enter the complete short address on PS3In the PS3 Internet Browser, type the displayed http://ps3.themezer.net/T… address. You do not need to load Themezer’s modern main website on the PS3.
  3. Finish the download and applySony says theme downloads through the browser install when the download completes. Follow the console’s prompts, then select the installed theme in Theme Settings and choose Apply. Prompts may vary by firmware.
  4. Use USB if the connection failsA modern website, certificate or network error may stop an older console browser. Save the P3T on a phone or computer and use the documented USB route above.

Storage, removal & limitations

Keep a copy; change it whenever you like

Each card shows the P3T download size. Keep enough free system storage for installation; the displayed file size is not a measured installed-space requirement. Your saved USB or phone copy is separate from the installed theme.

To switch back, choose a built-in theme in Theme Settings. To remove an installed theme, select it in the theme list, press the confirm button and choose Delete, as described in Sony’s manual. Keep your original P3T if you may reinstall later.

Theme Settings is different from XMB modification

These P3T downloads customize theme artwork, icons, sounds or backgrounds. They do not install custom firmware, change firmware files, add a PS4 operating system, or provide a custom XMB loader.

Replacing flash resources, fonts or XMB components is a separate homebrew workflow with its own CFW/HEN and firmware requirements. Do not follow those instructions to install an ordinary P3T.

Check the result on your console

Creators may supply only some icons; Sony notes that missing artwork can keep default icons or use another icon from the theme. Themes with multiple backgrounds may choose one randomly. Preview appearance, sounds and animation can differ with display and brightness settings.

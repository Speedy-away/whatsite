Before you start

Use the PS3 build of Apollo on a PS3 that can run homebrew. Start your supported CFW or enable HEN as your setup requires, then install the PS3 package from the existing save-tools page.

  • Log into the local PS3 user that should own the save.
  • Close the game and back up its existing save slot.
  • Use a PS3-readable FAT32 USB drive.
  • Match the game’s title ID, region, update and required DLC.

Apollo detects the current user and console settings on first run. The PS4 Activate PS4 Accounts menu is not part of this PS3 save-resigning workflow.

What does “switch the PSN ID” mean?

For a save, this usually means resigning it for the account that will load it. The save’s owner is separate from your public PSN username.

PSN Online ID
Your visible username. Typing a different username into a save folder does not transfer ownership.
Account ID
The account identifier recorded in save metadata. Apollo displays it as 16 hexadecimal characters, for example 0123456789abcdef. Use the destination account’s real value.
Local User ID
A user number on this console. It is separate from the Account ID and can differ on another console.
Game / title ID
For example BLUSxxxxx or BLESxxxxx. This identifies the game build or edition; it is not an account.

Keep an untouched backup of both the source save and the destination account’s existing save. Changing ownership does not make a save compatible with another game, edition, update or platform.

1. Back up before changing the owner

  1. Copy your current save to USB.From the PS3 Game column, open Saved Data Utility (PS3), select your save, open its options and use Copy to the USB drive where permitted. Keep the complete save folder.
  2. Use Apollo for copy-protected data when supported.Open HDD Saves, choose the save and use Copy save game to USB. This copies the full save folder directly, including copy-protected saves. If you later need the normal PS3 copy menu, use Remove copy protection on a working copy and apply the changes; keep the untouched Apollo backup.
  3. Store an untouched copy elsewhere.On a PC, copy the full save folder from PS3/SAVEDATA into a dated backup folder. Keep PARAM.SFO, PARAM.PFD and all game files together.

2. Reassign a save to your current PS3 user

This is the normal “change PSN ID on a save” route. Apollo uses the destination user and console settings it detected. Keep the unmodified source in your backup.

  1. Prepare a USB working copy.Extract the downloaded save if necessary. Place the complete game-save folder under PS3/SAVEDATA on the USB drive, preserving its original contents and directory name.
  2. Use the destination local user.Log into the PS3 user that should load the save, run Apollo, and open USB Saves. Select your working copy.
  3. Check its details.Confirm the title ID and slot. The source save’s account may differ from your local user; that is the ownership you are about to reassign.
  4. Apply changes and resign.Use the save’s Apply Changes & Resign action to rebuild its ownership/signature for the configured user and console. Wait for Apollo to report success. Enabling an unrelated gameplay cheat is not required.
  5. Copy it back and load it.Copy the resigned save to the destination user’s internal saved data with Apollo’s copy operation or Saved Data Utility (PS3). Read any overwrite prompt, then launch the matching game under that same user and verify the correct progress.

Resigning updates metadata and signatures. It cannot turn a PS3 save into a PS4 save or guarantee compatibility between different games or save formats.

3. Advanced: choose another account owner

When you need a specific owner rather than the automatically detected current user, Apollo PS3 supports owner profiles through owners.xml. This is an advanced override; most users can use the current-user route above.

  1. Collect the intended destination’s real details.The official owner format includes owner name, local User ID, Account ID and console PSID; IDPS is required for license import/export. Use the intended owner’s genuine values and keep console identifiers private.
  2. Prepare the owner file.Follow the owner XML schema in the official PS3 README. Save it to /dev_hdd0/game/NP0APOLLO/USRDIR/owners.xml. Preserve a backup of an existing owner file before editing it.
  3. Select the correct owner.Open the save’s SFO Patches → Change Account ID menu and choose your prepared owner. Check the destination account before applying changes.
  4. Finish by resigning.Use Apply Changes & Resign, then transfer the prepared copy and test it as the intended user. Choosing a name in the owner menu does not by itself finish the save operation.

The built-in Remove ID/Offline option clears an account identifier, and Fake Owner/Rebug is not your real destination account. Choose your own prepared owner when assigning a specific account.

Do not copy the sample PSID or IDPS from a tutorial into your real owner profile. Those placeholders are not your console’s identity. A public PSN username is not an Account ID.

4. Restore backups and use Online Database saves

Restore your own backup

Close the game. Put the complete original folder back under PS3/SAVEDATA/ on USB. Use Saved Data Utility (PS3) → USB device → the save → Copy, or Apollo’s copy operation. Confirm the title and slot before overwriting. If the destination user differs, resign a working copy for that user first.

Download inside Apollo

Open Online Database, select the exact game and save, and download it to the offered destination. Then open the save in the appropriate save list and resign it before loading it in the game. The project explicitly requires resigning downloaded PS3 saves.

Read the contributor’s requirements for game region, update, DLC and save slot. Keep your own progress before trying a completion or modded save.

USB folder outline

PS3 game save on USB

USB drive/
└── PS3/
    └── SAVEDATA/
        └── <original game-save folder>/
            ├── PARAM.SFO
            ├── PARAM.PFD
            ├── ICON0.PNG  (when supplied)
            └── <game save files>

On the PS3, Apollo scans /dev_usb00x/PS3/SAVEDATA/ for USB saves and /dev_hdd0/home/000000XX/savedata/ for the current local user’s HDD saves. XX is the local User ID, not the PSN username.

The folder immediately inside SAVEDATA is the save itself. Do not leave it inside an extra archive-name directory, and do not copy only PARAM.SFO.

Patches, unlocks and memory cards

Save patches
Select only patches offered for your exact supported save. Start with one change, apply and resign, then verify it in the game before stacking more changes.
Copy protection
Apollo supports removing the copy-lock flag from supported PS3 saves. This enables copying; it does not replace resigning for a different owner.
PS1 and PS2 saves
Apollo has separate virtual-memory-card import/export and PSV conversion tools. Those formats and paths differ from PS3/SAVEDATA. Use the official format tables before converting a memory card.
Trophies and licenses
These are separate tool groups with their own account and console requirements. A game-save transfer does not transfer a trophy set or PSN purchase.

Keep PS3 instructions separate from the Apollo PS4 guide. The PS4 activation, encrypted USB containers and keystone procedures are not interchangeable with PS3 save handling.

Troubleshooting

My save is missing from USB Saves.

Check the drive is PS3-readable FAT32, extract the archive, and put the complete original save folder directly under PS3/SAVEDATA. Reload the list. A PS4 save or a PS1/PS2 memory-card image belongs to a different workflow.

The game still reports another owner.

Confirm the PS3 user you logged into and whether owners.xml is overriding automatic detection. Reopen the working save, select the intended owner if needed, finish Apply Changes & Resign and copy that prepared version back to the intended user.

It says Copying Prohibited.

Preserve a backup. Use Apollo’s supported copy/unlock operation for that save; the normal PS3 copy menu may remain restricted until its copy-lock flag is removed. Then resign separately if the owner is changing.

The save appears but is corrupt or incompatible.

Check the exact game/title ID, update, DLC and all original save files. Do not swap PARAM.SFO by itself or assume that renaming BLES/BLUS directories converts regions. Restore your original if a working copy still fails.

Do I need the PS4 activation instructions?

No. Apollo PS3 automatically detects the current user and console for normal save resigning. Its own backup/activation features are separate from the PS4 User Tools workflow.

Can I transfer online progression or convert PS3 progress to PS4?

Local resigning changes save ownership. Server-side account progress and cross-generation conversion require support from the game or publisher; Apollo ownership changes alone do not provide them.

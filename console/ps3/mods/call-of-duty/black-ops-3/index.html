Archive labels BO3 Nonhost, Pre, CFW/HEN; separate EBOOT paths are BLES02166 and BLUS31527. README identifies 0.1 Beta, warns of missing options/crashes, requires 720p for ESP and L1/R1 controller layout for aimbot. Exact firmware and game update unspecified.
Region / title
BLES02166 / BLUS31527

Choose the supplied files

  1. Use one matching EBOOTThe README says to copy only the EBOOT for the installed BO3 region. The archive provides game/BLES02166/USRDIR/EBOOT.BIN and game/BLUS31527/USRDIR/EBOOT.BIN. Preserve the original executable.
  2. Choose and rename one SPRXUnder tmp/Q_CE, choose one supplied SPRX variant and rename it Q_BO3_CE.sprx as the archive marker instructs. The README recommends Only Filled In because Full Non Filled In displays many unimplemented options.

Documented controls and prerequisites

  • The README lists D-pad Left + L1 as the menu shortcut; D-pad Down toggles Air-Stuck.
  • Set BO3 to 720p for ESP and choose the controller L1/R1 layout for aimbot, as specified by the source.
  • While changing stats, hold L1 to scroll slower or R1 to scroll faster.
  • If the initial scroll bar is absent, the source says to press D-pad Up a few times. If number selectors scroll automatically, press D-pad Right once.

Beta limitations

The README warns that many options are missing or unimplemented and crashes are expected. It says development last occurred in early October 2020. These are source claims about this captured build, not a hardware test or a promise of later updates.

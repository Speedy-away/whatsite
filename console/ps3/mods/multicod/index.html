Match the build before copying files

Game update, title ID and firmware type are separate requirements. A HEN-labelled archive does not establish support for every HFW version. DEX-only SPRX files require the stated DEX environment; do not treat CEX, DEX and HEN as interchangeable.

Keep a backup of the original game files. Use each archive’s readme for the exact file destinations and loader. Downloading an SPRX does not load it; downloading a PKG does not install it. Windows RTM tools run on a computer and need the documented console-side connection method.

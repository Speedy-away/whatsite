      Included INSTALL AND CONFIG.txt

      Match the EBOOT region-family folder to the installed Minecraft title and place EBOOT.BIN in /dev_hdd0/game/<region/title ID>/USRDIR, as the source directs. Place MCV4.5.sprx in /dev_hdd0/tmp. Family labels do not establish every title ID; preserve the original executable.

      Keep the two HUD instructions distinct

      The main setup note says to change the game HUD to HUD 1. The separate Menu Not Showing Fix instead says Help & Options > Settings > User Interface > scroll down > change HUD-Size to 2. Both source instructions are retained rather than silently choosing one; neither supplies an opening shortcut or exact game-update requirement.

Documented menu controls

  • Demonic Revelations: hold R2 and press R3 to open; D-pad Up/Down scrolls, X selects/toggles, Circle backs out or closes.
  • jedijosh Trainer: hold R1 and press D-pad Right to open or instantly close; directional pad scrolls, X selects and Circle backs out.
  • Bite's menu: hold L2 + Triangle to open or instantly close; D-pad Up/Down scrolls, X selects and Circle backs out.

Source-reported conflicts and required assets

The README recommends running one menu at a time because combining Demonic and jedijosh increases crash risk. It also warns against running both custom-weapon scripts together. Template files are required for all-animal models in Demonic and can alter matchmaking pool behavior; the jedijosh prebuilt branch omits those templates. These are source reports, not tested behavior.

Loose content is not source code

The loose branches contain compiled CSC scripts and runtime CSF/XML/CTD assets, not a supplied C/C++ project. The archive separately contains optional custom video assets designated for the game root rather than update/RPF locations; none were played. Preserve all original files and use the branch matching the installed GOTY title.

Match the build before copying files

Game update, title ID and firmware type are separate requirements. A HEN-labelled archive does not establish support for every HFW version. DEX-only SPRX files require the stated DEX environment; do not treat CEX, DEX and HEN as interchangeable.

Keep a backup of the original game files. Use each archive’s readme for the exact file destinations and loader. Downloading an SPRX does not load it; downloading a PKG does not install it. Windows RTM tools run on a computer and need the documented console-side connection method.

OunceCake

Dump unencrypted romFS game assets and exeFS executable files from your own Switch 2 games, updates and DLC, including digital games, cards and Switch 2 Editions.

Requirements: The RPC-capable ns2jb fork linked in OunceCake’s README, an active run folder, Node.js, console LAN address and an FTP client.

Setup: Follow the project’s RPC setup, then run node ouncecake.cjs <path-to-ns2jb-run> and select your game. When FTP is ready, connect to the console on port 2121 using Binary/Image (TYPE I) transfer mode. The console loads the files before extraction; no system keys or independent decryption are supplied. Use your own games and keep extracted files private.

Pinned complete script/source ZIP with bundled FTP engine. Requires the separately labelled RPC fork; Node.js22+.

OunceCake setup guide

  1. Extract the complete package

    Keep ouncecake.cjs, package.json and engine together. The ZIP includes the native FTP helper; no build step is needed for the bundled helper. Install Node.js22+ and an FTP client.

  2. Start the required RPC host

    Use the separate kurumuz RPC fork download and its README. Start node run.cjs --rpc <computer-LAN-IP>, complete the console handshake and keep the live host open.

  3. Select the title

    In the OunceCake folder run node ouncecake.cjs /absolute/path/to/ns2jb-rpc/runs/switch2-RUNID. Select your own game, update or DLC and wait for the FTP-ready message.

  4. Copy the dump

    Connect the FTP client to the Switch2LAN address on port2121, with Binary/Image(TYPE I) transfer mode. No username/password is required by this server. Copy romFS assets and exeFS files to a new computer folder with enough free space.

  5. Close the session

    Complete transfers before stopping the RPC host. Preserve your private dumps separately from these software packages; no games, keys or commercial assets are included.

Packages are pinned script/source snapshots, not upstream binary releases. GitLab snapshots are reconstructed from unchanged, Git-hash-verified files when upstream ZIP downloads are unavailable. Required runtimes are listed above; no console execution was performed here.

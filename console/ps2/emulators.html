FCEUmm-PS2

A native NES/Famicom emulator with a controller-friendly browser, save states, turbo buttons and multitap support. This is the standard USB-oriented ELF, not the separate CD/DVD build.

  • NES
  • Famicom
  • Save states
  • Multitap
Requires
An ELF launcher, PS2 pad and your own NES ROM dumps or compatible homebrew ROMs. Normal NES cartridges need no BIOS. Famicom Disk System software additionally needs your own compatible disk-system BIOS.
Download ELF (603.1 KB)
Official project Setup documentation Exact release
Setup & verified files

Copy the ELF and a separate ROM folder to FAT32 USB, launch it and choose a ROM in its browser. Configure a writable save path. Cross is A, Square is B and L1 opens the menu. ROMs and external BIOS files are not included. If upgrading from an old FCEUmm setup, back up the old FCEUltra.cnf and reset that configuration for this release’s controller mapping.

PicoDrive · native PS2

The upstream PS2 build of PicoDrive for Sega Mega Drive/Genesis and related systems. Keep its skin and configuration files with the executable.

  • Genesis
  • Mega Drive
  • Mega CD
  • Standalone
Requires
A homebrew PS2 and your own supported game dumps. Cartridge games need no Mega CD BIOS; Mega CD requires a matching region BIOS dumped from your own hardware. See the included readme for supported BIOS filenames.
Download upstream PS2 bundle
Official project Setup documentation Exact release
Setup & verified files

Extract the full PicoDrive folder to FAT32 USB and launch PicoDrive.elf. Select opens its menu. For CD games, keep BIN files with their CUE and load the CUE so track layout is preserved. BIOS files go beside the emulator as described in readme.txt. This standalone release does not use RetroArch BIOS filenames.

Storage & dependency checklist

  1. Start with a working ELF boot methodA downloaded ELF does not make an unmodified PS2 boot homebrew. Use the model-specific FMCB/OpenTuna guidance above, then launch apps through wLaunchELF or a configured menu. No region bypass is required by these homebrew downloads; the boot method still depends on your model and ROM.
  2. Use a conservative USB starting pointFAT32 USB is the starting layout for these instructions. PS2ME explicitly requires it. Memory Card Annihilator’s mca_new supports exFAT. Do not assume that an older app gains exFAT, SMB or MX4SIO support because OPL can use a device.
  3. Keep package folders and assetsExtract ZIP or TAR.GZ files on your computer before copying them. SuperTux needs its APPS tree at the USB root. PicoDrive needs its skin/config files. A direct ELF is only convenient where its optional or external dependencies are explained on its card.
  4. Separate USB, SMB and internal HDD supportOPL 1.1.0 offers USB, SMB and internal HDD routes; these are OPL features, not universal app services. Internal-HDD tools need a real internal drive interface. The Quake ports document their own USB/APA-PFS loading paths. SMB requires working Ethernet and share settings.
  5. Bring the right data and savesNES cartridge ROMs, Mega CD BIOS files, Java JARs and Quake PAKs are different requirements. They are not included in these runtime downloads. SuperTux includes its free game data. Keep an original save backup and a memory card available for apps that save there.
  6. Match the display and controllerUse a PS2 pad for the documented controls. Follow each app’s PAL/NTSC options; do not force an unsupported display mode. PadOS normal is 4:3 with Widescreen OFF. A theme changes OPL’s interface and does not patch game rendering.

Packages were checked for their paths, CRCs where applicable and ELF32 little-endian MIPS executable headers. SHA-256 values identify the exact downloaded bytes. No downloaded executable was run and no physical-console installation or performance test was performed.

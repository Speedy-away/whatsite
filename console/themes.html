Install for your console

Nintendo Switch

Copy the .nxtheme files to SD:/themes/, extract your own HOME Menu data when prompted, then install the selected menus and reboot into CFW.

Full setup & recovery Installation reference

Nintendo 2DS & 3DS

Use the theme manager’s documented SD folder and import flow. HOME Menu themes, Luma splashes and badge sets are separate content types.

Full setup & recovery Installation reference

Nintendo Wii U

Themiify and StyleMiiU load themes from SD:/wiiu/themes/. Follow the theme’s own format instructions and keep the original Wii U Menu files.

Full setup & recovery Installation reference

PlayStation 3

Put the P3T file in /PS3/THEME/ on a compatible USB drive, then open Settings → Theme Settings → Theme → Install on the PS3.

Full setup & recovery Installation reference

PlayStation Portable

Copy themes to ms0:/PSP/THEME/ (Memory Stick) or ef0:/PSP/THEME/ (Go internal). Apply PTF in Theme Settings; CTF also needs the matching firmware and CXMB. Follow the PSP page’s ARK-4 plugin instructions.

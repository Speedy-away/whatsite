New to GTA V Modding?

Follow this simple guide to get started with mod menus

1 Choose Your Mod Menu

Pick a mod menu from the sections below based on your needs:

  • Beginners: Start with Nenyoo, Riptide, Yim
  • Advanced Users: Try Infamous (paid) (more features)
  • Looking for Lua Scripts? Check the Lua Scripts section above

2 Download & Extract

Click the download button on your chosen menu and extract the files:

  • Right-click the downloaded .zip file
  • Select "Extract All..." or use WinRAR/7-Zip
  • Extract to a safe location (e.g., C:\GTA_Mods)

3 Launch GTA V

Start your game before injecting the menu:

  • Launch GTA V through Steam, Epic Games, or Rockstar Launcher
  • Wait until you're fully loaded into Story Mode or Online
  • Make sure the game is running in Windowed or Borderless mode for easier menu access

4 Inject the Menu

Run the mod menu injector as administrator:

  • Right-click the menu's .exe file
  • Select "Run as Administrator"
  • Press the menu's hotkey (usually Insert or F4) to open it in-game
  • Success! The menu should now appear in your game

  • Don't use in public lobbies

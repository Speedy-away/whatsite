Yo another Release c:

Had this for my own, but why not share it.

What can this Tool do?
- Connect to your Ps3 (CCapi/Tmapi)
- Change your Bo2 Stats (prestige/level)
- Give you the sticky Ghosts Camo on EVERY Weapon (Online, Private, League)
- Give you Sticky camos for your Online Weapon. (Digital CE INCLUDED)
- Set your Primary Weapon (Secondary Weapon can be set as Primary)
- Set your Secondary Weapon (Every single Primary Weapon can be set a Secondary) !DOUBLE DSR, ETC POSSIBLE!
- Set 2nd Attachment (Primary Weapon)
- Set 3rd Attachment (Primary Weapon)
- Set 1st Attachment (Secondary Weapon)
- Set 2nd Attachment (Secondary Weapon)
- Set Every Single Perk for Perk 1,2,3,4,5 and 6
- Change your Primary grenade to everything possible (Every Primary Weapon, Every secondary Weapon, every primary grenade and every tactical grenade)
- Change your tactical grenade to: (Some Primary Weapons, some secondary weapons, some primary grenades (Semtex, etc), tactical grenades)
!4 Weapons Classes are possible! (set up your OWN 4 Weapons class)
- Change your Wildcards (Very Buggy!)
- Change Reflex Crosshair from primary Weapon
- Change ED-Tech Crosshair from primary Weapon
- Change ACOG Crosshair from primary Weapon
- Change Hybrid Crosshair from primary Weapon
- Set checkerboard Scorestreaks

Tutorial for Double Weapons:
- You NEED the Wildcard Overkill
- The 2 Weapons NEED to have DIFFERENT attachments!

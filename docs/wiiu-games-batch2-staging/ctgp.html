Downloads

If you need help installing CTGP Revolution, see the install guide.

To use CTGP-R, you'll need:

  • A Wii or a Wii U
  • A Mario Kart Wii game disk
  • An SD card of at least 768MB

If this is the first time you've ever used CTGP-R or a homebrew application you'll need to download an exploit (see below).

Download CTGP-R v1.03 and extract it to your SD card. Say 'Replace All' or 'Merge' if you are prompted to overwrite any files.

CTGP-R is a free fan-made project. You can help support our server costs by donating!

 
Download CTGP-R v1.03
 

If you have an old version of CTGP-R and need to save space on your SD card for the extraction you can delete everything in the folder sd:/mkwii, except sd:/mkwii/My Stuff. After installing, the channel will delete old files from previous CTGP-R versions.

To help prevent online cheating, the source code for version 1.03 is kept secret, but the source code for the previous version is available on Github.

Exploits

An exploit is a mistake in the Wii or one of its games that allows you to run unofficial code on a Wii. Using an exploit voids your Wii's warranty. The exploit you need to download depends on what Wii version you have. Find the most appropriate exploit below.

Previous CTGP-R users

If you have used a previous version of CTGP-R you do not need to download an exploit. Just download CTGP-R v1.03 and launch from Riivolution as normal. You will be taken to the new channel.

Riivolution users

If you have Riivolution on your Wii you do not need to download an exploit. Just download CTGP-R v1.03 and launch Mario Kart Wii from Riivolution. You will be taken to the new channel.

Homebrew Channel users

If you have the Homebrew Channel on your Wii you do not need to download an exploit. Just download CTGP-R v1.03 and run the channel from the Homebrew menu.

Wii U users

Wii U users must use a Wii U exploit. All known Wii U exploits for Wii U rely on you owning certain Wii games. See WiiUBrew for a list of known exploits. Copy one of these exploits to your SD card then install CTGP-R v1.03 BEFORE running the exploit.

Wii version 4.3

Wii 4.3 users must use the letterbomb exploit Go to HackMii and follow the instructions to get a download. Extract this to your SD card then install CTGP-R v1.03 BEFORE running the exploit.

Wii version 4.2

Wii 4.2 users must use the 4.3 bannerbomb exploit. Extract this to your SD card then install CTGP-R v1.03. Then insert your SD Card and Mario Kart Wii into your Wii. Go to Wii Settings. Go to Data Management. Go to Channels. Go to SD Card. A message should appear saying "Load boot.dol/elf?". Press Yes. You will probably see a screen asking you to update IOS37. If so, press A to let it update.

Wii version 3.2 - 4.1

Wii 3.2 - 4.1 users must use the 3.2-4.1 bannerbomb exploit. Extract this to your SD card then install CTGP-R v1.03. Then insert your SD Card and Mario Kart Wii into your Wii. Go to Wii Settings. Go to Data Management. Go to Channels. Go to SD Card. A message should appear saying "Load boot.dol/elf?". Press Yes. You will probably see a screen asking you to update IOS37. If so, press A to let it update.

Older Wii versions

Older Wii versions should be updated before installing CTGP-R. Update your Wii then follow the instructions for the updated version.

Help & FAQ

Common questions about cheats, mods, and safety

Getting Started

How do I download a cheat or mod?

Open the game you want from Free Cheats, or a game from Game Mods, then press the Download button on the cheat you want.

Most downloads are hosted on our own file host and open in a new tab. Some link straight to the mod author instead, which is deliberate — you always get the original file rather than a re-upload.

Why do I have to disable my antivirus?

Cheats inject code into a running game and read or write its memory. That is exactly what malware does, so antivirus software flags it. This is a false positive: the behaviour looks the same even though the intent is not.

  • Turn off real-time protection before you extract the file
  • Add the folder to your exclusion list so it is not deleted later
  • Turn protection back on once you are done

Only do this for files you actually trust. If a download came from somewhere other than this site, scan it first.

What do I need installed first?

Most Windows cheats need the Visual C++ Redistributables. Missing them is the single most common cause of a menu that opens and immediately closes.

Script mods usually need a script hook too — Script Hook V for GTA V, Script Hook RDR2 for Red Dead. Install that before any mod that depends on it.

See Requirements for the full list.

How do I install a mod menu?

The usual sequence:

  1. Extract the archive somewhere outside your game folder
  2. Start the game and load into single player
  3. Run the injector or loader as administrator
  4. Pick the game process and inject
  5. Open the menu with its hotkey, usually F4, Insert or Numpad /

Every menu ships a readme. If the hotkey here does not work, that is the file to check.

Downloads & Links

A download link is dead or will not open

Tell us and it gets fixed. The fastest route is Discord or Contact.

Before reporting, try disabling your ad blocker for the page. Blockers sometimes stop the redirect that carries you to the file host.

What is bstlar.com?

It is the file host used for most downloads on this site. When you press Download you land on a bstlar page with the file on it.

Links that point somewhere else — GitHub, a mod author’s own site, Mega — are intentional. Those are the official sources and we would rather send you there than mirror the file.

Where do I get the key for a mod menu?

A few menus use a rotating key. Open the key page linked from that menu and the current key is shown on it.

Keys rotate on a fixed schedule, so one you saved earlier will stop working. Load the page again for the current one rather than reusing an old key.

Why are there ads on the download pages?

Ads are what keep everything here free. Nothing on this site is paywalled and there is no membership.

If an ad ever tries to install something, close it — that is not a download from us. Our files only ever come from the Download button itself.

Safety & Bans

Can I get banned for using cheats?

Yes. Anti-cheat systems detect and ban, and there is no cheat anywhere that removes that risk.

  • Bans on GTA Online and similar are often tied to hardware, not just the account
  • Use single player wherever you can
  • If you go online, use an account you can afford to lose
  • Never use a cheat on an account with purchases on it

Read Safety before you use anything online.

Are all the cheats safe and undetected?

Files here are checked before publishing, but undetected is never permanent. A cheat that was safe last month can be detected after a single game or anti-cheat update.

Status badges on each card reflect what was true when it was last checked. Treat them as a guide, not a guarantee.

Should I use my main account?

No. Use a throwaway account for anything online.

An alternate account costs far less than losing a main with years of progress and purchases on it.

A cheat is not working. What now?
  1. Check the game updated — a patch breaks most cheats until they are rebuilt
  2. Run the injector as administrator
  3. Confirm the Visual C++ Redistributables are installed
  4. Make sure your antivirus has not quietly deleted a file
  5. Re-download in case the archive was incomplete

Still stuck? Ask in Discord with the game, the cheat name, and what actually happens.

Game Mods

What is the difference between a cheat and a mod?

A cheat injects into the running game to give you an advantage — aimbot, ESP, a trainer menu.

A mod changes the game itself: graphics overhauls, new vehicles, new scripts. Mods live under Game Mods and are generally the safer, more accepted side of things.

Do mods work in online modes?

Assume not, and do not try. Graphics mods are sometimes tolerated, but script mods and anything that alters game files will get you banned online.

Keep a clean copy of the game if you want to play both modded single player and online.

A game update broke my mods

Normal. Script hooks tie themselves to a specific game build, so a patch stops them working until the author rebuilds.

Wait for the update rather than forcing an old version. Forcing it usually crashes on launch.

Console & Emulators

Can I mod my Nintendo Switch?

Only if your console is an unpatched model. Later hardware revisions cannot run custom firmware without a physical modchip.

Check your serial number before buying anything. Our Nintendo Switch page covers Atmosphère and what to back up first.

Do I need a modded console to use emulators?

No. Emulators run on your PC and need nothing done to your console.

You do need game files, and those should come from discs or cartridges you own. See Emulators.

Which emulator should I use?

Depends on the system — PCSX2 for PS2, RPCS3 for PS3, Dolphin for GameCube and Wii, Xenia for Xbox 360, shadPS4 for PS4.

RetroArch covers most retro systems in one place. Every one is listed with its official download on the Emulators page.

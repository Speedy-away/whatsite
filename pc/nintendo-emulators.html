Setup, requirements & compatibility
Requirements
No packaged release exists on this exact repository’s releases page at the check date. The README documents Windows MSYS2 MINGW64 builds. Its Linux instructions are explicitly untested; no macOS build or support was verified.
Set up
Use the exact repository’s README and dependency documentation if you intend to build it. The documented output is build/bin/eden.exe with the required MinGW/Qt runtime files. Supply your own extracted game dump, keys and firmware. Compatibility
Upstream lists selected Switch 2 games as playable or booting, with slowdown and graphics caveats. These are author-reported results, not tests performed by this site. Read the exact title, update and GPU notes in the repository before assuming compatibility.

Set up your emulator

  1. Choose the exact host packageMatch Windows, macOS or Linux, CPU architecture and the app’s minimum OS. Experimental and source-build labels describe different routes.
  2. Keep the whole package togetherExtract ZIP/7z packages into their own folder. Follow the project’s runtime, driver and installation instructions. A console homebrew package cannot run as a desktop app.
  3. Configure required console filesSome emulators need your own BIOS, firmware, keys or system modules. Open the card’s requirements and official guide for exact formats and locations.
  4. Configure controls and savesMap a controller, choose a writable save location and test one game. Keep saves backed up before changing versions or switching forks.
  5. Use the compatibility trackerResults depend on the exact game update, emulator build and hardware. Source-only research entries are not a promise that a game will run.

Thanks for downloading Hestia!

Put "Hestia_Mw2.sprx" in /dev_hdd0/tmp/
and put "EBOOT.BIN" in your Modern Warfare 2/USRDIR directory.

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Controls:
Host Menu
- L1 + R3 = Open
- X = Select
- Dpad Up/Dpad Down = Scroll
- Square = Back

No-Host Menu
- Dpad Left = Open
- Square = Select
- Dpad Up/Dpad Down = Scroll
- Circle = Back

~~ Enjoy

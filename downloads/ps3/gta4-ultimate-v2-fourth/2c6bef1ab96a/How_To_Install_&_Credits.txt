Installation Instructions:

NOTE: THE 1.1 UPDATE IS NOT MANDATORY ANYMORE

Natural timecycle and new icons:	copy "ps3.rpf" to /dev_hdd0/game/TITLE_ID/USRDIR/ps3.rpf 
						copy "frontend_menus.xml" to /dev_hdd0/game/TITLE_ID/USRDIR/update/data/frontend_menus.xml (skip this part if you don't have this directory or if you haven't updated the game)
						ONCE YOU ARE DONE REMEMBER TO ENABLE THE "Noise" OPTION IN THE DISPLAY SECTION OF THE PAUSE MENU

New radar/map/HUD:	copy "radar.img" to /dev_hdd0/game/TITLE_ID/USRDIR/ps3/models/cdimages/radar.img 
				copy "frontend_ps3.ctd" to /dev_hdd0/game/TITLE_ID/USRDIR/update/textures/frontend_ps3.ctd

Better Textures (vehicles, weapons...):	copy "vehicles.img" and "weapons.img" to /dev_hdd0/game/TITLE_ID/USRDIR/ps3/models/cdimages/
							ROADS: copy "gtxd.img" to /dev_hdd0/game/TITLE_ID/USRDIR/ps3/data/cdimages/gtxd.img
							TREES: copy "ext_veg.img" to /dev_hdd0/game/TITLE_ID/USRDIR/ps3/data/maps/props/vegetation/ext_veg.img

Additionals Visual Modifications:	FOR DISK/ISO USERS, copy "common.rpf" to /dev_hdd0/game/TITLE_ID/USRDIR/common.rpf 
						FOR PSN USERS, you'll need to follow this tutorial on how to encrypt the common.rpf archive https://www.reddit.com/r/ps3homebrew/comments/pichgn/tutorial_porting_or_making_gta_iv_mods_from_pc_to/ 
						or, alternativly, if you have NPEB00882/NPUB30702 Title ID you can download the one I've already made but you'll need to rename it to "common.edat"

Find your Title ID: https://gamefaqs.gamespot.com/ps3/933036-grand-theft-auto-iv/data

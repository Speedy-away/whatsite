~~~~~[How to Install]~~~~~
1. Extract "Mod Loader BUZZARD v5.3 Private".
2. Open FileZila / mmCM.
3. If you use FileZila, go in you're PS3/Settings/Network Settings/Settings and Connection Status List/Search for you're IP Address.
4. If you are using HEN, be carreful to Enable HEN and check that you have FTP enabled it can be used on this differents homebrews : webMAN MOD, multiMAN, REBUG TOOLBOX etc...
5. Enter this IP Adress on you're FIleZila Host and press Enter Key.
6. Transfer the "update.rpf" to "/dev_hdd0/game/BLES01807/USRDIR".
7. BUZZARD Mod Loader need an modded EBOOT to work. SO you can use the one you already have, or you can use one in the folder, gived an EBOOT for CEX/DEX/HEN. If needed, transfer the "EBOOT.BIN" to "/dev_hdd0/game/BLES01807/USRDIR".
8. Launch GTA as you usually do.
9. You're done, enjoy !

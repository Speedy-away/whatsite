PS4 ezRemote Server has no storage-detection endpoint. Open ezRemote on the console and copy the actual mounted path, for example /mnt/usb0 only when that device is present. Numbers do not identify physical USB ports.

Prepare download folder opens the same installed companion through the running ezRemote Client (port 8080). Press Create there to create only missing whatwhatboy directories and verify existing ones. The client app must stay running; the background receiver alone cannot create folders. Internal storage defaults to /data/whatwhatboy. A supported USB HDD, SSD or flash drive must expose a writable file-storage mount. PlayStation Extended Storage is system-managed. Keep room for the download and an extracted or installed copy.

Queue records and automatic retries belong to ezRemote. Use its native file manager to inspect a failed transfer or partial file; this page does not delete files or send automatic retry requests.

Ready files do not need archive extraction. PKGs still need installation, payloads need a compatible loader, and plugins, cheats or patches need their documented setup and supporting files. Original and prepared archives remain available under Archive files. Their extraction links open the running client’s preparation page; reviewed archives up to 32 MiB receive a checksum check before extraction into a new folder.

PS4 checks for existing target files and partial downloads before queuing; it cannot verify the parent folder through this server API. Confirm the folder in ezRemote first. “Receiver reports complete” reflects the receiver’s status. It does not verify the saved file’s hash or console compatibility. Keep the receiver running and follow each project’s firmware and installation requirements.

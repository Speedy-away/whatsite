Outfit XML Files: Self Options > Appearance > Outfit XML Files.
Choose File and enter a name without .xml, then Dump Current Outfit to XML.
FTP files from /data/Expulsion/outfits to back them up or share them.
Put custom Expulsion XML v1 files in this folder. Choose the same filename, then Import Outfit XML.
Existing exports are not overwritten: choose another name.
Imports require the same character model and valid component/prop variations. Undo restores the previous clothing/accessories.
This format stores model hash, 12 clothing components (drawable, texture, palette), and 8 accessory props. It does not store face blend, hair tint, tattoos, weapons or GTA saved-outfit-slot metadata.
Menyoo and other XML schemas are not supported by this importer.

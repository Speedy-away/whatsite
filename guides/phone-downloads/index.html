Save downloads on iPhone & Android

Save downloaded files to Files on iPhone and iPad or Downloads on Android. Find browser downloads, use file sharing, copy links and troubleshoot file saving.

Saving a file
StartTest savingiPhone & iPadAndroidHelp

Start with the file

Tap the file’s Download button. On a phone, File options also provides a copyable link and saving instructions.

Where your browser supports it, prepare a file and then tap Save or share file to choose an app or folder. If that option is unavailable for a file, the normal download link remains available.

Check saving on your phone

Try this small text file, then find phone-download-check.txt in Files or Downloads. You can open it to confirm the file finished saving.

Download test file

For the optional share route, tap File options, prepare the file, then tap Save or share file. On iPhone, choose Save to Files, select a folder and tap Save. On Android, choose a file app if one is offered, or use the normal download.

Opening the share sheet does not save the file by itself. Finish the save in the app or browser, then check that the file is there.

iPhone & iPad

  1. Download in your browserTap Download and confirm the browser’s download prompt if it appears. Wait for it to finish.
  2. Find the fileOpen Files, tap Browse, then open Downloads. Depending on your settings, it may be under iCloud Drive or On My iPhone / On My iPad. Safari’s Downloads button also opens the download list.
  3. Save an open previewIf your browser shows a supported file preview, open Share and choose Save to Files, choose a folder, then tap Save.
  4. Choose a download folderOn iPhone, open Settings → Apps → Safari → Downloads to choose a location.

Android phones & tablets

  1. Download the fileTap Download. Your browser may ask where to save it or ask you to confirm the download.
  2. Find the downloadOpen the phone’s Files or file manager app and look in Downloads. In Chrome, the browser menu also contains Downloads.
  3. Use the link menuYou can touch and hold a direct file link and choose Download link.
  4. Move or share itUse the file manager or Chrome’s Downloads list to share the completed file or move it to another folder.

If a file does not save

  1. Try your full browserIf a link opens inside a social or messaging app and cannot download, copy the file link and open it in Safari, Chrome or your usual browser.
  2. Use the original downloadFile options keeps the normal download link available. For large files, use that link and let the browser manage the download.
  3. Check the provider pageExternal hosts may require their own download button or sign-in. A source or project page is not the file itself.
  4. Check what was savedIf the saved item is a sign-in page or an HTML error page, return to the provider and use its actual file download. Renaming a webpage to .zip or .bin does not turn it into the intended file.
  5. Check space and connectionMake sure the phone has enough free space, then retry a failed download from the browser’s Downloads list.
Keep the original filename. Saving a PC or console file to your phone stores it for transfer. Use it on the device and game version listed with that download.
Saving steps vary by browser and file type. Browser help is linked above. Report a broken link.
